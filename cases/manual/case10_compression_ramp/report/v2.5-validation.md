两个生产网格的默认最大 Jacobian 参考相对差阈值均为 0.2；SD7003 实测 0.174783、拐角 0.00185383。拐角极小 smoke 的流向间距跳变较大，实测约 0.315，专用 smoke 配置阈值为 0.9，仍要求正 Jacobian 且未降阶；**生产网格没有放宽该阈值**。

最终日志 `validation/final-*.log`、`field-checks.log`、`serial-mpi4.json`、拐角 `repartition-restart.json` 为主要证据。源码开发中较早的三步 smoke 和网格尝试不作为最终包的验证证据。本机未创建最终物理解，未用 smoke 输出冒充参考结果。

## 重跑

开发仓库可执行：

```bash
ctest --test-dir glm_test/build-serial -R 'wcns.chapter5|wcns.unit|wcns.periodic_hill|wcns.stage_k_solver.serial' --output-on-failure
python tests/test_chapter5_postprocess.py
python tools/verify_v2_5_release.py
```

算例包中的 `validation/configs/` 保存实际短算输入。重跑时先把输入复制到算例根目录，保证相对网格路径正确，并选择新的输出目录。`maximum_steps` 返回码 2 属于预期有界终止，不应当作数值失败。对应生成器/审计器输出在 `mesh-generation.log` 和 `metrics.log`。

打包采取白名单，只包含相关源码、说明、网格、参考数据和最终短算日志；不包含历史用户输出、编译目录、临时 Python 依赖或完整流场结果。源码包另作独立编译与清单校验，记录在 `package-validation.txt`。
