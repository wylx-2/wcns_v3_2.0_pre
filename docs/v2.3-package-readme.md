# WCNS v2.3 Linux 源码包

本目录由受控 Git 提交确定性生成，只包含程序源码、CMake、内置 CGNS 源码、必要工具、文档
和两个配置模板；不包含测试、网格、算例结果、构建目录或开发中间文件。

先核验完整性和来源：

```bash
sha256sum -c PACKAGE_CONTENTS.sha256
cat WCNS_SOURCE_REVISION
```

串行构建：

```bash
cmake -S . -B build-serial \
  -DCMAKE_BUILD_TYPE=Release \
  -DWCNS_ENABLE_CGNS=ON \
  -DWCNS_ENABLE_MPI=OFF \
  -DWCNS_BUILD_TESTS=OFF
cmake --build build-serial --parallel 4
cmake --install build-serial --prefix install/serial
```

MPI 构建：

```bash
cmake -S . -B build-mpi \
  -DCMAKE_BUILD_TYPE=Release \
  -DWCNS_ENABLE_CGNS=ON \
  -DWCNS_ENABLE_MPI=ON \
  -DWCNS_BUILD_TESTS=OFF
cmake --build build-mpi --parallel 4
cmake --install build-mpi --prefix install/mpi
```

复制 `examples/full_case_template_v2.3.wcns` 后修改网格、初场、边界、算法和输出；所有候选项
都在模板中列出。槽道 t=250 分叉可使用
`examples/channel_retau180_from_t250_all_speed_roe.wcns`。正式运行前必须执行：

```bash
install/serial/bin/wcns_run --config case.wcns --dry-run
```

v2.3 与 v2.2 的配置和 checkpoint 身份兼容；核心算法不变可 `strict` 续算，改变核心算法须
选择 `restart.mode=algorithm_change`。详细操作见 `docs/linux-server-guide.md`，算法和配置见
`docs/riemann-solvers-v2.2.md`、`docs/all-speed-roe.md` 与 `docs/config-reference-2.md`，本次优化
和验收结果见 `docs/performance-optimization-v2.3.md` 与 `docs/v2.3-validation.md`。

本包未附带大型物理验证结果，也不代表程序已完成 Case06 或三维翼型服务器验收。
