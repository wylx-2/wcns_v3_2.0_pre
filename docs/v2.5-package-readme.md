# WCNS v2.5 源码包

新增第五章 SD7003、超声速压缩拐角的无湍流模型 ILES 初始化/入口/转捩源、时间与展向统计、MPI 检查点恢复和多块结构网格工具，保留 v2.4 周期山。

详细内容见 [调研报告](docs/chapter5-v2.5-research.md)、[使用和统计说明](docs/chapter5-v2.5-implementation.md)、[验证记录](docs/v2.5-validation.md)。两个网格及参考结果分别位于相邻 SD7003 / compression_ramp 算例包中。公开表值与近似数字化曲线有明确区分；未提供不存在的精确原始谱数据。

```bash
sha256sum -c PACKAGE_CONTENTS.sha256
cmake -S . -B build-mpi -DCMAKE_BUILD_TYPE=Release -DWCNS_ENABLE_CGNS=ON -DWCNS_ENABLE_MPI=ON -DWCNS_BUILD_TESTS=OFF
cmake --build build-mpi --parallel 4
```

串行构建将 MPI 改为 OFF。依赖和服务器迁移见 [Linux 指南](docs/linux-server-guide.md)。紧凑源码包不包含开发测试目录，因此 BUILD_TESTS 保持 OFF；验收日志随算例包提供。

本机仅运行短步验证。SD7003 显式步长约 5.86×10⁻⁸ c/U∞，推进完整统计窗成本很高；必须先在服务器评估。网格通过几何检查不等于物理精度已验证。

`WCNS_SOURCE_REVISION` 标识父提交与工作区快照，`PACKAGE_CONTENTS.sha256` 标识交付内容；没有把未提交修改冒充 Git 发布标签。
