
## 2. 必须接受的范围边界

| 项目 | 前置 AA 内完成 | 后续阶段关闭 | 禁止的解释 |
|---|---|---|---|
| 定常 LU-SGS | 层流与 SA-neg；Rusanov/HLLC/Roe 未预处理路径 | Y 补 SST/k-epsilon；Z 补 LES | AA 通过不代表尚未实现模型已通过 |
| 非定常隐式 | BDF1 启动、BDF2 双时间，层流/SA 二阶时间验证 | Y/Z 各自补模型时间精度与状态事务 | 不得把未收敛内迭代当作物理步 |
| 低 Mach | Roe + Weiss--Smith，层流/SA，定常和非定常 | Y/Z 做对应模型非退化回归 | 不得只修改声速或 CFL 冒充预处理 |
| 通用模型接口 | 任意数量标量、刚性源、代数闭合谱半径、halo/restart/接受事务 mock | Y6/Z11 用真实模型闭合 | mock 只证明接口，不证明 SST/LES 物理 |
| X 物理验证 | AA 批准后由 X-B 完整执行 | 无 | 不得降低阈值、减少网格或用 smoke 替代 |
| Case06 | 不读取、不改写、不作为 AA 性能基准 | AB 冻结工况后正式验收 | 不得把用户 Case06 冒充独立 TMR |

AA 性能对照改用已登记散列的独立 TMR finite-flat-plate level 6 和 NACA0012 225；完整多网格
物理结论仍属于 X-B。Y/Z 的新增模型耦合最后还必须进入 AE 全组合发布矩阵。

## 3. AA 自动验收卡口（前置版本）

人工批准本单只授权开始 AA 设计/实现，不预先批准 AA 结果。AA 完成后仍须逐项自动通过：

1. **G0 规格**：冻结《算法补充》12.7、12.8、12.15 的矩阵、特征、$D/L/U$、MPI sweep、
   BDF 历史、内迭代停止、缩步/失败和 future-model contract；阈值必须在运行前落盘。
2. **G1 接口**：平均流与 SA 场、任意数量 mock scalar、源 Jacobian、边界 halo、checkpoint 和
   接受/拒绝只存在一个权威事务；不支持组合在分配状态前一致失败。
3. **G2--G5 工程回归**：`git diff --check`、格式/警告、干净串行/MPI Release 构建、安装、
   公式/单元和全部现有 CTest 通过；`integrator=ssprk3, preconditioner=none` 保持冻结基线。
4. **G6 数值正确性**：`beta=1` 恢复普通 Roe；$M=10^{-1},10^{-2},10^{-3}$ 压力扰动呈
   $O(M^2)$；定常解与解析/收紧显式参考一致；BDF2 在收紧内迭代误差时达到二阶。
5. **G6 性能**：相同硬件、分区、初场、空间残差和停止标准下，TMR 平板 level 6 与 NACA 225
   达到 AA0 预先冻结的迭代数和墙钟改善；不得用宽松残差或 smoke 结果制造加速。
6. **G7 并行/重启**：1/2/4 rank 的扫序、停止原因、物理层接受、场、SA、载荷和统计一致；
   同/异 rank 恢复保存 BDF 历史、伪迭代和预处理签名，无死锁或重复采样。
7. **G8 证据**：报告包含命令、构建/硬件、输入散列、阈值、原始日志、误差/阶/墙钟图表、
   候选提交和工作树；失败卡口不得创建候选。

自动全过后才可创建不可移动的 `v2.0.0-aa-candidate.N`，并再次停下做 AA 结果人工判断。
