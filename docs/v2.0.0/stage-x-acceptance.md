# v2.0.0 阶段 X 自动验收

结论：**阶段实现和原非长算卡口已完成，AA 自动卡口已通过并创建
`v2.0.0-aa-candidate.1`。2026-09-14 起 X-B 改按本机轻量 L 级验收，全部本机长算已停止；
细网格物理证据列为服务器 S 级。新的 L 级收尾与干净回归尚未完成，暂不创建 X 候选标签。**

改写或用作 SA 验收替代物。

## 3. 卡口发现的阶段依赖

规范近壁网格的全局显式 SSPRK3 稳定步长实测为：

| 网格 | 首步 `dt` |
|---|---:|
| flat plate level 6 / 5 / 4 | $8.67\times10^{-9}$ / $3.44\times10^{-9}$ / $1.36\times10^{-9}$ |
| NACA0012 225 / 449 / 897 | $4.56\times10^{-9}$ / $1.82\times10^{-9}$ / $6.78\times10^{-10}$ |

这些数值不是数值失败，而是 resolved-wall 网格在“全局显式步长”下的预期刚性。
项目负责人已批准执行 `X-A → AA → X-B`。AA 的层流/SA 本地伪时间、LU-SGS、低 Mach、串行/
MPI 全矩阵已经通过并由提交 `e0a2a05`、标签 `v2.0.0-aa-candidate.1` 固定。随后实测证明在本机
继续多网格长算成本过高。按 2026-09-14 新授权，X 保留全部公式和离散阈值，但把本机完成定义
改为 L 级；原细网格容差不放宽，只移动到 S 级服务器任务。Case06 仍不能替代独立 TMR。

## 6. 2026-09-14 L 级小算例

使用 NACA validation 225x65（14,336 cells）、$\alpha=10^\circ$、SA-neg、单 rank、LU-SGS、
`CFL=1` 运行 200 accepted steps。运行前预算检查通过；求解器配置含
`run.max_wall_time=1800`、checkpoint 每 200 步，实际墙钟 `201.555 s`。

- 停止原因为 `maximum_steps`，明确不解释为定常收敛；
- 总残差 `9.05142 -> 0.341323`，下降 `1.42355 decades`；峰值/初值 `1.0`、终值/初值
  `0.03771`，通过 L 级 `2.0/1.5` 界限；
- 200 步全部接受，场有限，`minimum_rho=0.963411`，无模型 floor/投影；
- 最终 field、boundary、history、loads、manifest 和 step-200 checkpoint 均写出，产物约
  `3.4 MiB`，低于预算。

该结果关闭 X 的小算例条目；候选前的干净串行/MPI 全矩阵及汇总报告仍未关闭。
