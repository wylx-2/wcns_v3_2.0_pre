## 4. 发现与处置

阶段 W 的原失败为“部分连接块面不允许张量守恒权重”。X-A 的过渡修复使 dry-run 能通过，
但 AB0 审查发现守恒权重按有界线构造、连接子段的通量散度却仍使用中心线，两者没有共同的
$D^Tw=e_R-e_L$ 证明。AB0 没有沿用“能启动即正确”的判断，而是统一模板选择并用任意面通量
回归封闭证明。该修复局部降低尾迹切口邻近的边界阶数，但不改变完整连接面内部模板。

## 5. 人工冻结点

进入 AB1 前必须由项目负责人提供或批准：

1. Mach、弦长 Reynolds 数、攻角、侧滑角和参考温度；
2. 绝热/等温壁，气体与 Sutherland 参数，全湍流或转捩假设；
3. SA-neg/SST 的远场湍流量或强度、长度尺度、黏度比；
4. 参考面积/弦长/力矩中心及 lift/drag 方向；
5. 定常 RANS 或 BDF2 双时间 URANS 目标；
6. 参考数据、来源、Cp/Cf/y+ 站位、CL/CD/CM 容差和收敛阈值；
7. 至少三级系统网格，或允许另行提交离散误差替代方案；
8. 网格资产策略和服务器单次/总预算。

在这些输入冻结前，AB 不建立 laminar/SA/SST 正式配置，不估算 $y^+$，不运行原网格时间步，
不创建 `v2.0.0-ab-candidate.N`，也不进入 AC。
