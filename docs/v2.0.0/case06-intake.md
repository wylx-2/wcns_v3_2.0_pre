## 3. 正式计算前仍缺少的输入

下列内容由项目负责人或后续目标算例资料提供，并在阶段 AB0 人工冻结：

1. 来流 Mach 数、弦长 Reynolds 数、攻角、侧滑角和参考温度；
2. 壁面热边界（绝热或给定温度）、气体和 Sutherland 参数；
3. 转捩假设。v2.0.0 核心只承诺全湍流 RANS；若要求自然转捩，必须另立范围变更；
4. SA-neg、SST 等模型的远场湍流量或其物理输入（湍流强度、长度尺度、黏度比）；
5. 参考面积、弦长、力矩中心以及升力、阻力方向；
6. 比对数据及其来源、允许误差、需要输出的 `Cp/Cf/y+` 站位和积分载荷；
7. 目标是定常 RANS、时间平均 URANS，还是二者都要；
8. 是否允许把网格纳入开发仓库、仅在本机按哈希引用，或放入独立算例资产仓库。

在这些量未冻结前可以验证“能读取、能分区、能保持自由流”，但不能宣称 Case06 已通过物理
验证，也不能自行选取文献工况替代用户目标工况。

## 4. 阶段 AB 的最低证据

- 原文件与可选转换文件的哈希、转换工具和映射可追溯；
- 串行及至少 2/4 rank 的网格覆盖、连接互逆、度量和自由流保持通过；
- `laminar`、`sa_neg`、`sst` 三个配置的参数摘要、restart signature 和失败路径明确；
- 表面 `Cp`、压力/黏性 `Cf`、`y+`、`mu_t/mu`、残差和载荷历史可重读；
- 至少三个系统网格或经批准的替代离散误差方法，不能从单一网格声称网格无关；
- 低马赫开/关对照说明精度与收敛效率，高 Mach 恢复测试证明预处理关闭极限一致；
- 所有结论区分代码验证、算例数值收敛和实验/高可信参考数据验证。
