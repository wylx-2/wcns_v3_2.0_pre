### 2.1 AB0 几何与度量基线

安装树 `wcns_inspect_structured_mesh` 的只读结果为：x 范围
`[-484.456616747519,501.000007802345]`，y 范围
`[-507.806809185105,507.806808886941]`；全部 229,376 个四边形面积为正。翼面含 512 段，
x 弦长为 1，前缘为 `(0,0)`，尾缘两端点 gap 为 0。翼面边长范围
`[1.00944632978e-4,9.84751675190e-3]`；壁面线与第一层网格线的中点间距 min/mean/max 为
`8.15361116599e-7 / 8.30320345125e-7 / 9.48966716616e-7`，最低法向对齐度为
`0.999378659489`（1 为正交）。

PHengLEI/SCMM6 的最小 Jacobian 分别为 `9.56721928183e-11` 和 `9.54285474741e-11`，均为正且
fallback cells 为 0。全域最大边长约 33.546、最小约 `8.1397e-7`，体现近壁与远场的强尺度
跨度；后续必须结合冻结的 Re、壁面处理和增长率检查，不能从几何高度直接声称 $y^+$ 合格。

## 3. AB1 冻结输入

项目负责人指定 TMR 页面后，现固定：$M=0.15$、$Re_c=6\times10^6$、$T_\infty=300\,K$、
$\alpha=10^\circ$ 主工况、绝热无滑移壁、完全湍流、$Pr=0.72$、$Pr_t=0.9$；弦长和单位翼展
参考面积均为 1，力矩中心为四分之一弦长。SA-neg 远场比为 3；SST-2003m 从
$I=0.052\%$、$\mu_t/\mu=0.009$ 换算。配置、公式和参考散列见
`cases/validation/case06_naca0012/` 与《算法补充》12.17。

原始网格继续只按上述 SHA-256 引用，不纳入 Git。主目标是定常 LU-SGS；URANS 只在服务器
稳态证据表明确有必要且经过范围批准后启用，LES 明确排除。

尚待 v2 功能完成后冻结的是服务器的硬成本数值（rank、核时、内存、磁盘和单次墙钟），不是
物理工况。没有该预算不得提交 S 级任务；本机 L 级通过也不能宣称 Case06 已完成物理验证。

## 4. 阶段 AB 的最低证据

- 原文件与可选转换文件的哈希、转换工具和映射可追溯；
- 串行及至少 2/4 rank 的网格覆盖、连接互逆、度量和自由流保持通过；
- `laminar`、`sa_neg`、`sst` 三个配置的参数摘要、LU-SGS/物理时间设置、restart signature 和
  失败路径明确；
- 表面 `Cp`、压力/黏性 `Cf`、`y+`、`mu_t/mu`、残差和载荷历史可重读；
- SA 主分支至少使用 TMR 225/449/897 三级系统网格；SST-2003m 的 225 排错和 897 主解若没有
  完整三级趋势，必须明确保持“工程对照”而不能声称网格无关；
- 低马赫开/关对照说明精度与收敛效率，高 Mach 恢复测试证明预处理关闭极限一致；
- 所有结论区分代码验证、算例数值收敛和实验/高可信参考数据验证；公开 SSTm 曲线不能冒充
  SST-2003m 的严格同模型真值。
