## 2. 混合块面的离散选择

对逻辑方向 $d$、侧面 $s$ 和该侧的切向面索引 $t$，定义

$$
C_d^s(t)=
\begin{cases}
1,&t\text{ 被合法连接覆盖},\\
0,&t\text{ 为物理边界}.
\end{cases}
\qquad
A_d^s=\bigwedge_t C_d^s(t).
$$

- 若 $A_d^s=1$，该侧完整连接，连接邻域使用 profile 的内部中心通量差分模板；
- 若 $A_d^s=0$，该侧是物理边界、或物理/连接混合块面。该逻辑侧的所有法向网格线统一使用
  profile 的有界闭合 $D^B$；连接子段仍使用唯一共享面 Riemann/黏性通量，但不读取连接外的
  深层面通量模板；
- `phenglei_wcns` 影响连接侧第一层单元，`scmm6_wcns` 影响前两层单元；内部单元保持原阶数；
- 原始变量/模型变量梯度可以在合法连接子段读取状态或梯度 halo；本规则约束的是进入守恒方程
  的面通量散度，不能把两类算子混为一谈。

设 $w^d$ 满足 $(D^B)^Tw^d=e_R-e_L$，切向张量权重为 $w_t$。对混合低侧有

$$
\sum_t w_t\sum_n w_n^d(D^B\widehat F)_{t,n}
=\sum_t w_t\left(\widehat F^+_t-\widehat F^-_t\right).
$$

把低侧分成物理集合 $P$ 和连接集合 $C$。互逆共形连接给出索引双射 $\phi:C\to C$；共享面
所有者和方向变换保证

$$
\widehat F^-_{\phi(t)}=-\widehat F^-_t,
\qquad w_{\phi(t)}=w_t.
$$

所以连接项成对严格相消，只留下 $P$ 上的物理边界净通量。这一方案继续使用正的张量积分权重，
不需要求一个未经验证的非张量权重场；代价是在尾迹切口邻近采用有界闭合。若连接不互逆、
切向权重不匹配、同一面索引被重复覆盖或连接分支不相容，初始化必须拒绝。

## 3. 实现边界

- 在网格拓扑层提供唯一的“整侧完全连接”判定，守恒权重和所有守恒通量散度共享同一语义；
- 无粘平均流、黏性平均流和 SA-neg 通量散度都按该判定选择中心/有界模板；两方程 RANS 当前
  使用相邻面两点守恒差分，不需要额外高阶边界切换；
- 不修改 CGNS、不把整个下 `j` 面误标为 wall、不忽略尾迹连接，也不把 dry-run 当作自由流或
  物理收敛证据；
- 本阶段不改变既有完整块面连接的中心模板，也不改变 `conservative_two_point` 路径。

## 4. AB0 自动卡口

1. 微型 C/O 型单块自连接覆盖“左尾迹连接 + 中间壁面 + 右尾迹连接”；连接侧必须选择有界
   闭合，完整多块连接仍选择中心模板；

3. 守恒权重为正，共享面切向权重失配小于 $10^{-11}$；非法重叠/非互逆拓扑继续拒绝；
4. 原始 Case06 文件哈希与 intake 一致；串行、2-rank、4-rank dry-run 均成功且 mesh signature
   一致；该检查不执行任何时间步；
5. 受影响单元测试、完整串行/MPI 回归、算法规格检查和 `git diff --check` 全部通过；
6. 报告明确区分：AB0 拓扑/代码验证、尚未执行的自由流推进、尚未执行的物理 RANS 验证。

## 5. AB1 物理与参考冻结

1. 主工况为 TMR 2DN00：$M=0.15$、$Re_c=6\times10^6$、$T_\infty=300\,K$、$Pr=0.72$、
   $Pr_t=0.9$、绝热无滑移壁和全湍流；$\alpha=10^\circ$ 是首要点，$0^\circ/15^\circ$ 是扩展点；
2. $c=S_{ref}=1$（单位翼展），力矩中心 $(0.25,0,0)$；drag/lift 随攻角旋转，公式见《算法补充》
   12.17；SA-neg 取 $\widetilde\nu_\infty/\nu_\infty=3$；SST-2003m 取
   $I=0.052\%$、$\mu_t/\mu=0.009$ 的等价 $L_t/c=4.300130725961134\times10^{-6}$；
3. Ladson tripped、$Re=6\times10^6$ 力数据作为实验主对照；Gregory--O'Reilly 压力只作形状
   对照，因为其 Reynolds 数约 2.88--3 million；TMR 没有实验 $C_f$；
4. CFL3D SA 数据用于 SA-neg 非负分支的代码到代码对照。公开 SSTm 数据与项目 SST-2003m
   模型身份不同，只设工程故障探测阈值，不宣称严格同模型验证；
5. 自洽主分支关闭 point-vortex；只有与 TMR 公开曲线同源比较的服务器分支使用 manifest 中
   固定 $C_L$。程序不做载荷反馈，输入的 $C_L$ 不能被当成预测；
6. 目标先做定常 LU-SGS RANS。只有残差/载荷显示不可忽略的稳态振荡且通过人工范围变更时，
   才增加 BDF2 双时间 URANS；二维 Case06 不运行 LES。

详细数值、URL、SHA-256 和阈值集中在
`cases/validation/case06_naca0012/manifest.json`，模板和生成命令见同目录 README。

## 6. AB1 L/S 自动卡口

### 6.1 本机 L 级

- 可执行测试必须反算 $M/Re/p_\infty^*$、SST 的 $k/\omega/L_t$、TMR 数据头量和攻角方向；
- laminar/SA-neg/SST-2003m 三套配置在 113×33（3,584 cells）上通过串行 dry-run；SA/SST
  至多各做一个不超过 20 accepted steps、300 s 的短探针，禁止用其载荷作物理结论；
- Case06 897×257 只做 SHA-256、只读网格检查和串行/2/4-rank dry-run，零时间步；
- 参考文件必须逐项 SHA-256 通过；模板生成器拒绝本机超过 20 步、超过 300 s、在本机开启
  固定点涡对照，以及没有墙钟上限的服务器配置；
- 受影响测试、完整串行/MPI 回归、算法规格和 `git diff --check` 通过。

L 级通过后允许创建明确标注 `S=pending` 的 AB 候选并继续 AC；它只代表实现/输入准备就绪，
不代表 Case06 已完成物理验收。

### 6.2 完整功能后的服务器 S 级

首要路径是 $\alpha=10^\circ$：SA-neg 在 225/449/897 做三级趋势，SST-2003m 先以 225 排错，
再运行 Case06 897 主解。两模型先无点涡，主解通过后才运行固定参考 $C_L$ 的同源对照；
$0^\circ/15^\circ$ 不得先于首要路径占用预算。每次运行必须有 commit/二进制/网格/配置散列、
rank、核时、内存、磁盘、checkpoint 和提前失败规则。

S 级同时检查残差至少 3 decades、末段载荷相对跨度不超过 0.2%、质量守恒、$y^+\le1$、
模型 floor/负分支/降阶、1/2/4 rank 与异 rank restart、低 Mach 开/关收敛解一致性，以及
manifest 冻结的积分量和曲线阈值。SSTm 对照通过仍必须保留“模型不完全相同”的限制。
