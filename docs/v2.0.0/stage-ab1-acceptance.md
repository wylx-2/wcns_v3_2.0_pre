## 1. 冻结结果

- 主工况采用 NASA TMR 2DN00：$M=0.15$、$Re_c=6\times10^6$、$T_\infty=300\,K$、
  $Pr=0.72$、$Pr_t=0.9$、绝热无滑移壁和全湍流；$\alpha=10^\circ$ 为首要点；
- laminar 仅作诊断；RANS 模型为 SA-neg 与项目实际实现的 SST-2003m。公开 NACA0012 SST
  参考是 SSTm，只能作工程故障探测，不能写成严格同模型验证；
- SA-neg 远场取 $\widetilde\nu/\nu=3$；SST 由 $I=0.052\%$、$\mu_t/\mu=0.009$ 换算为
  $k^*=4.056\times10^{-7}$、$\omega^*=270.4$、$L_t/c=4.300130725961134\times10^{-6}$；
- 自洽主分支关闭固定点涡；只有服务器同源对照分支使用 manifest 中冻结的参考 $C_L$，且
  该值是边界输入，不是计算预测；
- Ladson tripped、$Re=6\times10^6$ 力数据作为主要实验积分量对照；Gregory--O'Reilly
  压力只作曲线形状对照；公开资料没有可用于本工况的实验 $C_f$。

公式和模型身份见《算法补充》12.17；URL、数值、参考文件散列和服务器阈值见
`cases/validation/case06_naca0012/manifest.json`。

## 4. S 级后置项

完整 v2 通用功能完成后、AE 发布候选之前，服务器必须至少完成：

1. $\alpha=10^\circ$ 的 SA-neg 225/449/897 三级趋势，以及 SST-2003m 的 225 排错和 897 主解；
2. 无点涡自洽主解先通过，再做固定参考 $C_L$ 的同源 TMR 对照；
3. 残差至少下降 3 decades、末段载荷相对跨度不超过 0.2%、质量守恒、表面 $y^+\le1$；
4. `Cp/Cf/CL/CD/CM`、模型量、负分支/floor/降阶、低 Mach 开关、1/2/4 rank 和异 rank
   restart 检查；
5. 每次运行记录 commit、二进制/网格/配置散列、rank、核时、峰值内存、磁盘、checkpoint、
   提前失败规则和批准的预算。

S 级完成前，版本说明必须继续写明“Case06 物理验证 pending”，不得用本记录提升生产支持等级。
