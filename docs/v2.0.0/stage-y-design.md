# v2.0.0 阶段 Y 设计：两方程 RANS、壁面处理与 LU-SGS 耦合

状态：**Y0 公式与自动卡口已冻结；实现候选正在执行本机轻量 L 级验收，尚未通过。** 项目负责人
已授权 `AA → X-B → Y` 连续推进，中间不设人工等待；任何阶段自动卡口失败必须修复并重跑。
Y 的 L 级自动卡口通过并明确登记 S 级状态后停止，进入人工验收，不得提前开始 Z。

基线依赖为 X-A 的 SA-neg 输运和 AA 的 LU-SGS/BDF2/Weiss--Smith。用户 Case06 不属于 Y，
继续保持只读并留到 AB；未跟踪的 case05 长算结果也不得暂存或修改。

## 1. 完成定义与支持级别

Y 完成后程序必须具备基本 RANS 计算能力：层流兼容路径、生产级 SA-neg、生产候选
SST-2003m、通用 RANS 平均流黏性闭合、壁距、模型输运、定常 LU-SGS，以及可重启的 BDF2
双时间接口。标准高 Reynolds 数 k-epsilon 因本阶段缺少足够的独立物理数据库，只保留实验
支持，必须显式配置 `turbulence.experimental=true` 且只能配 `wall_function`。

核心 SST 采用《算法补充》12.1、12.2、12.5 的 modified SST-2003m：总能不含 $k$，平均流
应力省略 $-2\rho k/3$，生产项用应变率不变量并以 $10\beta^*k\omega$ 限制。不得用原始 SST、
SST-V 或涡量版本的常数/limiter 混入同一配置身份。

## 2. 实现任务

1. Y0：冻结 SST-2003m、标准 k-epsilon、远场换算、resolved/wall-function 边界和支持级别。
2. Y1：实现任意两输运量的守恒存储、统一平均流面质量通量、二阶上风模型重构、扩散和源项；
   非正面候选只允许逐面 donor 回退；接受状态的严格正变量允许使用《算法补充》12.2 的显式
   下界投影，但必须逐变量计数，不得无日志裁剪。
3. Y2：实现 SST 的 $F_1/F_2$、cross diffusion、涡黏度、生产 limiter、解析壁面 $\omega$、
   诊断字段及 modified 平均流应力/湍流热通量。
4. Y3：实现标准 k-epsilon 和显式实验开关；拒绝 resolved 壁面、缺实验声明及错误模型专属键。
5. Y4：实现对数律壁面函数；解析壁面和壁面函数均逐面输出壁距、摩阻速度、$y^+$ 与冻结
   区间分类，壁面函数另输出壁面面数、$y^+$ 范围和越界计数；越界仅报警，禁止自动切换。
6. Y5：扩展 field/history/manifest/checkpoint；保存模型身份、两输运场和全部 BDF 历史层，错误
   模型、常数、积分器或壁面签名必须在推进前拒绝。
7. Y6：将两变量耗散主导源 Jacobian 和模型扩散谱半径接入 AA 的 dense local block LU-SGS；
   平均流与模型增量共用全局可行线搜索，所有 rank 同时接受或恢复；选定全局松弛量后才允许
   对有限的严格正两方程变量投影，SA-neg 与平均流不适用。
8. Y7：完成公式、MMS、串并行、重启、定常/非定常和真实 RANS 算例证据，并形成候选报告。

## 3. 自动卡口

### 3.1 公式与离散

- SST/k-epsilon 的常数、$S^2$、$F_1/F_2$、cross diffusion、production limiter、涡黏度、源、
  扩散系数、远场换算和壁面值与独立标量式误差 `<=2e-12`；
- 局部两变量块与稠密解误差 `<=2e-11`，源 Jacobian 对守恒变量求导且不重复乘密度；
- 32/64/128 网格的两方程制造解 $L_1/L_2$ 观测阶 `>=1.90`，$L_\infty$ 观测阶 `>=1.80`；
- 正值面重构回退、整步恢复、最深 $2^{-20}$ 可行线搜索及下界投影/逐变量计数均有确定性测试。

### 3.2 配置、输出和重启

- 合法 SST、实验 k-epsilon、SSPRK3/LU-SGS、resolved/wall-function 组合通过；所有非法组合
  在读取/初始化阶段以精确原因拒绝；
- history 动态列和逐步 `<field>_floor_repairs`、CGNS 的 `k/omega/epsilon` 与诊断、manifest
  全程累计修复计数、数值签名和 checkpoint 两层
  历史均可重读；错误模型重启必须失败；
- 解析无滑移壁逐面 $u_\tau=\sqrt{|\boldsymbol\tau_t|/\rho}$、
  $y^+=\rho u_\tau d_1Re/\mu_w$ 与独立标量式误差 `<=2e-12`；分类边界 5、30、300 精确，
  输出不得反向修改求解状态或按分类自动切换壁面处理；
- 串行及 MPI 1/2/4 rank 的两步非均匀终态中平均流和两模型场最大绝对差 `<=1e-9`；第二步
  必须覆盖壁面/源项生成的模型梯度与扩散系数跨分区传播，均匀初场一步比较不计入本卡口。

### 3.3 时间推进与工程回归

- BDF2 线性衰减制造问题使用三层步长，$L_2$ 观测阶 `>=1.90`；未收敛物理层不推进时间；
- SST/k-epsilon 在相同空间残差下的 LU-SGS 终态与收紧步长 SSPRK3 对照一致；k-epsilon 只作
  数值接口证据，不据此升级支持级别；
- 干净串行/MPI Release 配置、全量构建、安装和 CTest 全过，`git diff --check`、文档链接、
  schema 1 与 v1.1.0 兼容回归全过。

### 3.4 具体 RANS 小算例与服务器验证

人工卡口前必须提交一个主小算例和一个补充小算例；它们验证计算通路和定性行为，不替代细网格
物理验证：

1. 主例固定为 NASA TMR 35x25 零压梯度平板，$M=0.2$、$Re_L=5\times10^6$、resolved
   SST-2003m；最多 2,000 accepted steps/1,800 s。残差峰值/初值不得超过 2.0，终值/初值不得
   超过 1.5；报告 $C_f$ 方向与数量级、壁面单位恒等式、
   $k/\omega/\mu_t$ 合法域、投影计数、质量缺陷和残差窗口，不要求短算达到物理收敛。
2. 补充例从 41x129 槽道和 103x28 no-plenum hump 中选择一个；使用相同墙钟/步数上限，检查
   对称/摩阻方向或分离趋势、边界分类、有限性和输出可重读。另一个只做 dry-run/首步 smoke。
3. 平板 69x49/137x97、槽道 81x257/161x513、hump 205x55/409x109 的充分定常收敛、三级趋势
   和原冻结 `Cf/u+/Cp` 容差全部保留为 S 级服务器任务。S 级未完成时 SST 只能形成算法候选，
   不能声称上述物理精度已经验证。

L 级小算例必须无非有限量/隐藏裁剪并保留配置、网格 SHA-256、版本、rank、命令、墙钟和输出
位置。正值投影逐变量报告，`omega/epsilon` 不得投影；小算例只要求末 100 步无投影且总投影率
不超过 `0.5%`。1/2/4 rank 使用更小的两步非均匀确定性问题验证，不重复物理长算。S 级继续要求
残差至少下降三个数量级、末段载荷窗口相对波动 `<=0.2%`、末 500 步无投影和原曲线阈值。

机器可读输入、来源、散列和全部阈值位于
[`cases/validation/sst_tmr/manifest.json`](../../cases/validation/sst_tmr/manifest.json)。
公共收敛/投影卡口由 `tools/analyze_rans_run.py` 执行；平板、槽道和 hump 分别使用
`tools/analyze_sst_flatplate.py`、`tools/analyze_tmr_channel.py`、`tools/analyze_tmr_hump.py`。
解析壁面逐面恒等式由 `tools/verify_resolved_wall_units.py` 使用完整三分量黏性牵引独立核验。
二维 CGNS 剖面必须由 `wcns_extract_rans_profile` 从真实顶点壁面位置抽取，禁止把第一层中心
平移成壁面。公式和离散误差定义见《算法补充》12.11。

## 4. 失败与候选规则

L 级小算例出现非物理解、回溯耗尽、持续指数爆发或偏离预冻结判别量即为自动卡口失败。修复
必须记录首个失败步、根因、受影响回归和重跑结果，不得在看到结果后放宽门槛。3.1--3.3 与
3.4 的 L 级全部通过后可创建标明 `S=pending|passed|failed` 的 `v2.0.0-y-candidate.N`；随后停止
并请人工检查模型身份、公式/离散证据、小算例、rank 等价、服务器清单、失败日志、Git 提交和
用户文件保护情况。
