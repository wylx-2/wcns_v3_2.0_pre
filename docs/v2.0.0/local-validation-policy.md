# v2.0.0 本机轻量验收与服务器算例策略

状态：**2026-09-14 起生效。** 本文件按项目负责人最新资源约束，替代各阶段设计中“在本机完成
全部细网格/长时间物理收敛”的执行要求；模型公式、离散阈值、守恒、MPI/restart、失败语义和
Git 卡口不放宽。

## 1. 两层证据及结论边界

1. **L 级（本机阶段卡口）**以公式和离散分析为主：独立标量公式、极限恢复、有限差分
   Jacobian、稠密小系统对照、MMS 阶、守恒/自由流/对称性、合法域与故障注入、微型多块
   MPI/restart，以及一个受限小算例的有限性和趋势检查。
2. **S 级（服务器物理验证）**用于 Case06 的 897x257 网格、细网格 RANS 收敛、三维 LES/机翼、
   长时间统计和其他超过本文件本机上限的任务。S 级必须先给出核时、内存、磁盘和最大墙钟预算，
   使用检查点和提前失败条件；未经预算批准不得提交。
3. L 级通过只证明“实现与冻结算法契约一致，具备进入下一开发阶段的候选能力”，不单独证明
   网格无关、统计充分或与实验高精度一致。生产支持等级所需的 S 级证据未完成时，版本说明必须
   明列限制；不得用 smoke 或短步结果替代。项目负责人于 2026-09-24 进一步要求所有 Case06
   大型计算等 v2 功能完整后再上服务器，因此 AB-L 可先进入 AC/AD，AB-S 必须在 AE 前关闭。

## 2. 本机硬上限

以下限制作用于阶段 X 之后新启动的验收运行；构建和纯单元测试不计作 CFD 算例。

| 项目 | 默认上限 | 强制规则 |
|---|---:|---|
| 二维网格 | 32,768 cells | 推荐不超过 225x65；更大网格转服务器 |
| 三维网格 | 65,536 cells | 只允许解析场或短小挤出/周期盒，不做生产 LES 统计 |
| 单个 smoke | 20 accepted steps | 只检查读取、拓扑、有限性和输出契约 |
| 单个物理探针 | 2,000 accepted steps | 若 30 分钟内不能提供预先定义的判别量，提前停止 |
| 单次墙钟 | 1,800 s | 配置必须显式设置 `run.max_wall_time` 并启用 checkpoint |
| 单阶段本机 CFD 总墙钟 | 7,200 s | 包括失败重跑；达到上限即停止算例、转分析或服务器 |
| 并发求解进程 | 2 | MPI 总 rank 数不超过 4；优先串行及 2-rank 定向比较 |
| 求解器合计内存 | 4 GiB | 预估超过上限时不启动 |
| 单阶段新增运行产物 | 1 GiB | 仅保留必要 history、摘要、最终小场和检查点；大场不入 Git |

例外必须由项目负责人逐项批准并写入阶段报告。先前允许的 897x257 LU-SGS 稳定参数诊断窗口
已经结束；阶段 AB 起 897 Case06 在本机为**零时间步**硬限制，只允许读取和 dry-run。新的稳定
问题应先用解析、单元/MMS 或 113x33（3,584 cells）定位，再提交有预算的服务器任务。

## 3. 非算例正确性证据矩阵

每个新增算法至少覆盖适用项，并由独立实现或解析式给出 oracle：

- 逐项公式与常数表、量纲/无量纲换算、旋转/反射/单位缩放不变性；
- `model=none`、`C_s=0`、`beta=1`、高 Mach 和零源/零梯度等退化极限严格恢复；
- 源 Jacobian、通量 Jacobian 和 LU-SGS 局部块的中心有限差分或复步校验，以及稠密直接解对照；
- MMS 的空间阶、BDF2 时间阶、离散滤波传递函数和已知协方差信号；
- 常量场保持、全局守恒、共享面反对称、壁面力/热流/单位恒等式、截面到整体加和；
- 最深回溯、投影计数、非有限量、损坏 checkpoint 和错误模型签名的确定性失败测试；
- 微型 1/2/4-rank 非均匀场传播及同/异 rank restart 等价。MPI 比较只缩小问题规模，不减少
  分区界面、halo、扫序和所有权覆盖。

评审时先检查上述证据，再检查小算例。若分析证据发现结构性错误，即使短算“看起来合理”也
必须判失败。

## 4. 小算例卡口

1. 每阶段最多选择一个主小算例和一个补充微型算例；在运行前冻结网格、步数/墙钟、判别量和
   失败阈值。
2. 短算只要求与其用途相称的结论：状态有限、守恒缺陷有界、预期对称性/方向正确、残差无持续
   指数爆发、模型量和诊断位于合法域、LU-SGS 相对显式或稠密参考给出一致更新趋势。
3. 不要求短算达到细网格物理收敛；`maximum_steps`/`maximum_wall_time` 不能写成 `converged`。
4. 阶段 Y 的具体 RANS 小算例使用 35x25 SST 平板作为主例，41x129 槽道或 103x28 hump 二选一
   作补充；阶段 Z/AC 使用不超过本文件上限的 Taylor--Green、解析滤波或挤出翼，不在本机采集
   生产湍流统计。

## 5. 服务器任务与成本卡口

满足任一本机上限即归类为 S 级。提交服务器前必须保存：代码提交和干净构建身份、网格/配置
SHA-256、rank/线程、预计与硬限制核时、峰值内存、输出上限、检查点周期、收敛/失败提前停止
规则和恢复命令。优先顺序为：

1. Case06 897x257 的 SA/SST 定常基线；
2. 为模型支持等级必需的最少细网格 RANS 对照；
3. 用户目标三维机翼的 RANS 基线；
4. 只有目标确实需要时才运行 LES 与长时间统计。

同一物理问题不得并发盲扫大量 CFL/松弛量。先在小网格和代数模型上排除明显错误，再在服务器
用 continuation 和检查点执行单一主路径；失败后先分析，未经新假设不得原样重跑。

## 6. 运行与 Git 纪律

- 本机物理探针必须设置正的 `run.max_wall_time`；现有配置契约会同时要求 checkpoint。结束原因、
  实际墙钟、峰值资源和最后完整检查点写入验收报告。
- 启动前执行 `python tools/check_validation_budget.py --config <case.wcns> --kind smoke|probe
  --dimension 2|3 --cells <cell-count>`；可同时传入阶段累计墙钟、并发数、预计内存和产物大小。
  返回非零即禁止启动。该检查器本身由 `wcns.validation_budget` 自动测试覆盖。
- 中断或超限段保留为诊断，不纳入通过证据；分析器按全局 step 去重，禁止拼接不同代码、网格
  或数值签名的轨迹。
- 运行期间固定二进制和 Git 提交。结果目录、checkpoint、服务器日志不提交；只提交小型配置、
  预算、摘要、散列和必要图表。
- L 级自动卡口全过后可创建阶段候选并继续开发；S 级状态在候选和版本说明中独立列为
  `pending|passed|failed`。v2.0.0 最终支持声明不得超过已取得的 S 级证据。
