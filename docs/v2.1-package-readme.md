# WCNS v2.1

WCNS 是面向二维/三维结构多块网格的高阶可压缩流动求解程序。v2.1 在 v2.0_pre 的
RANS/LES、Weiss--Smith+LU-SGS、壁面/载荷输出和可重启统计基础上，新增可直接配 SSPRK3 的
显式 `roe_all_speed`。

本目录只包含程序源码、离线 CGNS 构建依赖、一个 t=250 分叉配置模板和必要文档，不包含
网格、计算结果、完整算例或开发测试。大型 Case06、长期湍流及目标三维翼型没有在本机执行，
不能从版本名称推断工程精度。

## 构建

需要 CMake 3.20 以上和支持 C++20 的编译器。固定的 CGNS 4.4.0 源码位于
`third_party/cgns/`，默认不需要联网。

```text
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
cmake --install build --prefix install
```

MPI Release：

```text
cmake -S . -B build-mpi -DCMAKE_BUILD_TYPE=Release -DWCNS_ENABLE_MPI=ON
cmake --build build-mpi --parallel 2
cmake --install build-mpi --prefix install-mpi
```

精简目录不带开发测试，`WCNS_BUILD_TESTS` 默认关闭。

## 使用

```text
install/bin/wcns_inspect_structured_mesh <mesh.cgns>
install/bin/wcns_run --config <case.wcns> --dry-run
```

显式 all-speed Roe 的 schema 2 组合为：

```text
algorithm.riemann = roe_all_speed
time.integrator = ssprk3
preconditioner.type = none
```

它降低低 Mach Roe 的速度跳跃耗散，但仍受声学 CFL 限制。完整公式和检查点分叉步骤见
`docs/all-speed-roe.md`。`examples/channel_retau180_from_t250_all_speed_roe.wcns` 可从
case05 的 t=250 checkpoint 建立 SCMM6/线性 MDCD/`diss=0.001` 新分支；使用前必须替换路径、
输出目录和墙钟，并使用生成 checkpoint 时的原始网格（已核验 mesh signature
`18099232003167909757`），不能重新生成同名网格。

默认 `restart.mode=strict` 用于相同数值签名的连续续算。改变 Riemann、重构、时间推进等核心
算法时必须显式用 `restart.mode=algorithm_change`；它要求网格一致并保留守恒态与 step/time，
但会重置 BDF 历史、收敛基准和时间统计。

## 完整性与许可

`WCNS_SOURCE_REVISION` 记录来源提交，`PACKAGE_CONTENTS.sha256` 列出每个普通文件的 SHA-256。
WCNS 自有代码尚未选择对外许可证，本目录仅供内部使用；第三方 CGNS 使用其独立许可证，详见
`LICENSE.md` 和 `THIRD_PARTY_NOTICES.md`。
