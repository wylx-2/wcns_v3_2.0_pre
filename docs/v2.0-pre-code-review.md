# WCNS v2.0_pre 代码与算法审查报告

日期：2026-09-26

审查代码提交：`78a5bb23a09aa3412704bb0fc0f8ea3337531f3d`

## 1. 范围与结论

本轮直接审查 RANS/LES、低 Mach 预处理、LU-SGS、接受步统计及其主要运行时调用链，并检查
热循环中的重复构造、字符串查找和临时分配。审查没有改变模型常数、离散模板、浮点运算顺序
或用户配置语义；小型旧/新结果逐字段零容差一致。

审查结论是：当前公式实现与项目冻结的 SA-neg、modified SST-2003m、标准高 Reynolds 数
k--epsilon、Smagorinsky/尺度相似/动态/WALE、Weiss--Smith 和加权中心矩定义相符，未发现需要
改写离散算法的确定性错误。发现并修复了可避免的重复求值和堆分配；同时为 k--epsilon 不可用
的 resolved-wall 分支加入显式防御，防止未来配置约束变化后误套 SST 壁面公式。

这仍是实现正确性和小规模可执行性审查，不是湍流模型工程精度验证。

## 2. 算法核查

| 模块 | 核查内容 | 结论 |
|---|---|---|
| SA-neg | 正/负工作变量分支、负分支零涡黏、扩散系数、破坏项符号、源 Jacobian | 与冻结定义一致 |
| SST-2003m | `F1/F2`、应变率涡黏、10 倍生产限制、cross diffusion、守恒源 | 与 modified 约定一致 |
| 标准 k--epsilon | `C_mu k^2/epsilon`、生产/破坏、扩散和 wall-function 限定 | 公式一致；保持实验级 |
| LES | Smagorinsky、Bardina 相似、混合/动态、WALE 张量和耗散符号 | 与冻结定义一致 |
| 低 Mach | Weiss--Smith 参考速度、预处理矩阵逆、修正声学特征值、Roe+LU-SGS 限定 | 代数/配置门禁一致 |
| LU-SGS | 前后扫方向、标量/稠密源块/面块乘法、BDF1/BDF2 时间对角 | 单元与端到端门禁通过 |
| 统计 | `accepted_dt` 加权 Welford/Chan 合并、Favre 权、协方差、重启身份 | 更新和合并公式一致 |

主要公开对照为 NASA/AIAA Turbulence Modeling Resource 的
[SA/SA-neg 定义](https://tmbwg.github.io/turbmodels/spalart.html)与
[SST/SST-2003m 定义](https://tmbwg.github.io/turbmodels/sst.html)，以及 Nicoud--Ducros 的
[WALE 原始论文](https://doi.org/10.1023/A:1009995426001)、Weiss--Smith 的
[低 Mach 预处理论文](https://doi.org/10.2514/3.12946)和 Bardina--Ferziger--Reynolds 的
[尺度相似模型报告](https://ntrs.nasa.gov/citations/19800057410)。项目实际采用的无量纲化、
离散和支持边界仍以《算法补充》第 12 节为准。

## 3. 代码清理与效率修改

- 两方程边界同步复用求解器已经构造的模型对象，不再在每次残差前创建 registry 和模型；
- SA 与两方程源项、Jacobian 和诊断共用一次模型求值，删除同一单元内的重复完整计算；
- RANS/LES 热循环在进入单元循环前缓存湍流字段分量，移除逐单元字符串散列表查找；
- SA 与两方程单元上下文预先定长并循环复用，避免每个面/单元重复分配小向量；
- 全局时间步和隐式谱半径路径把描述符、分量索引和上下文移出单元循环；
- LU-SGS 稠密块和面块乘法复用固定 scratch buffer，不再按单元和 sweep 分配向量；
- 注释只保留算法约定、等价性理由和防误用条件；构建保持 `-Wall -Wextra -Wpedantic` 无新增
  诊断，`git diff --check` 通过。

新增 `wcns.lu_sgs.allocations` 自动门禁。在 128 cells、2 sweeps、2 variables 下，稠密块
路径只发生 9 次、面块路径只发生 6 次入口级固定分配；分配数不再随单元数或 sweep 数增长。

## 5. 剩余风险与服务器要求

- Linux 编译器、OpenMPI/MPICH、多节点 I/O 和调度器环境尚未在本机证明，需按
  [`linux-server-guide.md`](linux-server-guide.md) 做迁移预检；
- SA/SST/LES 仍需要 TMR/实验/DNS 细网格与网格收敛验证；实验性 k--epsilon 不升级支持等级；
- 低 Mach 与 LU-SGS 的微型门禁不能给出大型外流的最优 CFL、收敛率或壁钟成本；
- 源码没有外部 CI 和 sanitizer 平台矩阵，且 WCNS 自有代码许可证问题仍暂缓。
