# WCNS v2.0_pre 功能与统计支持矩阵

本表是 `v2.0_pre` 的发布能力清单。表中“可执行”只表示公式、配置、数据路径和小规模门禁闭合；
“物理待验证”表示尚未执行细网格、长时间统计或目标翼型，不应据此推断工程精度。

## 1. 求解与模型能力

| 能力 | 生产入口 | 本机证据 | v2.0_pre 支持等级 |
|---|---|---|---|
| 2D/3D 结构多块、共形连接 | `cgns_reader`、`StructuredPartitionPlan`、halo/共享面 owner | 几何、周期、多块、1/2/4-rank 回归 | 可执行 |
| Euler/层流 Navier--Stokes | 无粘/黏性 WCNS solver | 解析通量、制造解、微型运行 | 可执行；复杂流动物理精度不外推 |
| SA-neg | `sa_negative*`、模型输运/重启 | 源项、输运、壁面、隐式、重启微型门禁 | 可执行；Case06 细网格待验证 |
| modified SST-2003m | `two_equation_models`、`rans_two_equation_transport` | 解析模型项、输运、隐式、重启微型门禁 | 可执行；TMR 细网格待验证 |
| 标准高 Reynolds 数 k--epsilon | 同上，必须 `experimental=true`、wall function | 解析模型项与微型门禁 | 实验支持；不作生产精度承诺 |
| 五种 LES | `les_filter`、`les_models`、`les_closure` | 解析滤波/模型、Taylor--Green 微型场、1/2/4-rank、重启 | 可执行；HIT/槽道长期统计待验证 |
| Roe/Rusanov/HLLC | `riemann_solver` | 单元、边界和端到端微型门禁 | 可执行 |
| Weiss--Smith 低 Mach | `low_mach_preconditioner`，仅 Roe+LU-SGS | 矩阵/谱半径、稳态与双时间微型门禁 | 可执行；低 Mach 工程算例待验证 |
| SSPRK3 | `time_integrator` | 空间/时间制造解和稳健化回归 | 可执行 |
| 定常 LU-SGS | `implicit_time_integrator`、simulation solver | 扫掠代数、有限性、残差下降微型门禁 | 可执行 |
| 非定常 LU-SGS | BDF2，首步 BDF1，双时间内迭代 | 历史、接受/拒绝、checkpoint/restart 门禁 | 可执行 |
| 算法变更重算 | `restart.mode=algorithm_change` 状态导入 | 签名变化接受、守恒场逐值一致、历史/统计重置 | 可执行；不等同连续续算 |
| 通用三维翼型所需载荷 | 边界采样、整体力/力矩、展向分箱 | 解析面、分箱回收、1/2/4-rank 一致性 | 通用能力可执行；目标翼型未验证 |

算法定义及经典来源集中在《算法补充》第 12 节：SA/SST/k--epsilon 和低 Mach/LU-SGS 见
12.1--12.11，Favre 滤波 LES、Smagorinsky--Lilly、Bardina 相似、Germano--Lilly 动态模型、
WALE 与双时间 LU-SGS 见 12.12--12.16。文献一致性核查证明实现采用公开主流定义和明确的
受限变体，不替代网格收敛或实验/DNS 对比。

## 2. 可输出的瞬时量

| 类别 | 内建量 | 条件与语义 |
|---|---|---|
| 基本流场 | `rho,u,v,w,p,T,rho_u,rho_v,rho_w,rho_E` | 2D 的 `w/rho_w` 按二维状态解释 |
| 派生流场 | `sound_speed,mach,total_enthalpy,entropy_proxy,viscosity,jacobian` | 有限性和量纲缩放由 field registry 统一检查 |
| SA-neg | `nu_tilde,mu_t_over_mu,turbulence_production,turbulence_destruction,sa_negative_branch,wall_distance,wall_y_plus` | 仅 SA 配置注册；模型不匹配时拒绝 |
| SST | `k,omega,mu_t_over_mu,sst_f1,sst_f2,turbulence_production,turbulence_destruction,cross_diffusion,wall_distance,wall_y_plus` | 仅 SST 配置注册 |
| k--epsilon | `k,epsilon,mu_t_over_mu,turbulence_production,turbulence_destruction,wall_distance,wall_y_plus` | 仅实验 k--epsilon 配置注册 |
| LES | `mu_sgs,mu_sgs_over_mu,sgs_energy_transfer,sgs_stress_xx,sgs_stress_yy,sgs_stress_zz,sgs_stress_xy,sgs_stress_xz,sgs_stress_yz,les_dynamic_coefficient,les_filter_width,les_grid_anisotropy` | 五种 LES 共用稳定输出 schema；不适用项仍是该闭合的确定值，而非伪造物理统计 |

字段选择在启动时去重并检查注册身份；逐单元求值后再次检查有限性。模型字段随 checkpoint
保存；严格重启校验模型、字段布局、网格和算法签名。算法变更重算只在字段描述符匹配时导入
RANS 输运字段，否则按目标模型重新初始化。

## 3. 壁面、载荷与空间统计

| 输出 | 支持内容 | 自动约束 |
|---|---|---|
| 壁面瞬时量 | `p_w,T_w,mu_w,Cp,Cf,q_wall,friction_velocity,wall_y_plus,wall_y_plus_class` | 无粘/非壁面/模型不匹配的请求在输出前失败 |
| 牵引 | 压力、黏性和总 `traction_x/y/z` | 与整体载荷使用同一面状态、法向与黏性应力 |
| 整体载荷 | 压力/黏性/总力，三轴力矩，drag/lift 系数 | 全局物理面身份去重；2D 明示单位展向长度 |
| 展向载荷 | 用户给定右手方向和严格递增箱边界 | 每个面心恰入一箱；所有箱必须回收到整体载荷 |
| 守恒积分 | `total_mass,total_momentum_x,total_momentum_y,total_momentum_z,total_energy` | 原 zone 守恒权重和 MPI 全局归约 |
| x-z 平面 | 每个 cell-j 层的面积平均 `u`、x 向质量流率 | 只支持三维、规则共面层；越界/非共面拒绝 |
| y-z 截面 | 每个目标 x 的面积平均 `u`、x 向质量流率 | 只支持三维规则截面；无唯一支持面时拒绝 |
| 槽道壁面 | 上/下/平均壁面剪切、`u_tau`、`Re_tau` | 两个不同黏性壁 patch 和正半高必需 |

## 4. 接受步时间统计

时间统计对第 3 节已经注册的标量空间统计工作，不直接在每个网格点建立完整时间历史：

1. 只在物理步被接受后采样，权重严格为采样窗口内的实际 `accepted_dt`；伪时间迭代、拒绝步
   和重复 `(step,time)` 不采样；
2. 每个选中量输出 Reynolds mean/RMS 和以全局平均密度为权重的 Favre mean/RMS；
3. 对所有唯一量对输出 Reynolds/Favre covariance，在线更新使用稳定的加权中心矩算法；
4. checkpoint 保存量名次序、窗口、累计权重、样本数、中心矩和协矩；合法异 rank 重启继续
   同一统计，不合法身份或网格变化明确失败；
5. 串行、2-rank、4-rank 的连续运行与重启结果按门限比较，不允许以占位零值绕过无支持量。

## 5. 明确未内建的统计功能

`v2.0_pre` 不内建能谱、时间/空间自相关、置信区间、积分时间尺度、自动平稳性检测、任意曲面
插值统计或完整逐点 Reynolds 应力历史。长期 LES/RANS 统计的采样充分性也没有在本机证明。
这些量需在后续服务器验证中用明确的采样频率、窗函数、统计区间和不确定度方法完成。
