# WCNS v2.1 本机验证记录

日期：2026-09-29。环境：Windows 11、CMake 3.28.0、MinGW-w64 GCC 8.1.0，串行 Release，
CGNS 4.4.0 ADF。外部 CI 按项目约定未启用；未运行大型服务器算例。

## 1. 构建与全量自动测试

```text
cmake -S . -B ../build-v2.1 -G "MinGW Makefiles" \
  -DWCNS_ENABLE_CGNS=ON -DWCNS_ENABLE_MPI=OFF \
  -DWCNS_BUILD_TESTS=ON -DCMAKE_BUILD_TYPE=Release
cmake --build ../build-v2.1 -j 4
ctest --test-dir ../build-v2.1 --output-on-failure -j 4
```

结果：构建成功，`111/111` CTest 通过，最终复跑总测试时间 13.94 s。测试集包含既有 RANS、LES、
LU-SGS、Weiss--Smith、输出/检查点和发布 smoke，未发现回归。

## 2. all-speed Roe 专项卡口

| 卡口 | 结果 |
|---|---|
| registry/config | `roe_all_speed` 注册成功；schema 2 的 SSPRK3+none 组合可解析 |
| 一致性 | 左右均匀态通量等于解析 Euler 通量 |
| 低 Mach 修正 | 速度跳跃算例两支声学耗散均显著小于普通 Roe；物理谱半径保持相同 |
| 高 Mach 退化 | 超声速左右态的五分量通量和谱半径与普通 Roe 在 `5e-13` 容差内一致 |
| 几何对称 | 左右态互换并反向单位法向后，五分量通量反号 |
| 健壮性 | Sod 和高 Mach 状态通量/谱半径有限，无异常回退 |
| SSPRK3 运行 | 低 Mach 二维均匀流小网格实际推进通过，日志同时识别新通量和 SSPRK3 |
| 改算法重启 | 从 HLLC checkpoint 以 `algorithm_change` 切换；源/新 checkpoint 守恒场零容差一致 |
| case05 实际种子 | 64-rank Roe t=250 checkpoint 配原始网格 dry-run 成功；恢复 step 1047500、time 250、mesh signature 18099232003167909757 |

专项运行命令：

```text
ctest --test-dir ../build-v2.1 --output-on-failure \
  -R "wcns\\.(unit|run\\.all_speed_roe_ssprk3\\.serial|run\\.algorithm_change_restart|run\\.algorithm_change_restart_state)$"
```

连同 fixture 共执行 7 项，`7/7` 通过。

## 4. 结论与边界

结果支持“v2.1 的显式 all-speed Roe 公式已按文档实现，可与 SSPRK3 执行，可从旧 checkpoint
改变算法分叉，且未破坏既有本机测试”的结论。它不支持“长期槽道统计、NACA0012 或三维翼型
精度已经验证”的结论；显式时间步也仍受声学 CFL 限制。服务器正式运行前必须按
[`linux-server-guide.md`](linux-server-guide.md) 做 dry-run、2--5 步 smoke、资源上限和新输出
目录人工核查。
