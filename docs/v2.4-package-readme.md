# WCNS v2.4 源码包

基于 v2.3 的周期山 ILES 扩展，源码来自本次工作区快照。`WCNS_SOURCE_REVISION` 标识父提交及 worktree，`PACKAGE_CONTENTS.sha256` 标识实际交付内容；没有将未提交修改冒充为已提交版本。

源码包和 `WCNS_v2.4_periodic_hill_case` 算例包分开交付。源码包包含 CMake、内置 CGNS、核心源文件和必要工具／文档；测试结果和网格不混入源码包。详细设置见 [周期山报告](docs/periodic-hill-v2.4.md)，验证见 [验收记录](docs/v2.4-validation.md)。

```bash
sha256sum -c PACKAGE_CONTENTS.sha256
cmake -S . -B build-mpi -DCMAKE_BUILD_TYPE=Release -DWCNS_ENABLE_CGNS=ON -DWCNS_ENABLE_MPI=ON -DWCNS_BUILD_TESTS=OFF
cmake --build build-mpi --parallel 4
```

串行构建将 `WCNS_ENABLE_MPI` 改为 OFF。需要 C++20 编译器、CMake≥3.20；MPI 版需要目标服务器 MPI 开发环境。完整构建方式见 [Linux 指南](docs/linux-server-guide.md)，旧数值功能见 [用户手册](docs/user-manual.md)。源码包没有测试目录，`WCNS_BUILD_TESTS` 应保持 OFF；开发仓库保留验收测试。

进入相邻算例包后按其 README 先执行 dry-run 和 3 步 smoke。生产配置已准备，本机未启动长计算。v2.4 的新增功能和物理验证边界见 [发行说明](docs/release-notes-2.4.md)。
