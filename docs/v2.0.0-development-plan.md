## 1. 版本目标

v2.0.0 定位为“可验证的 RANS/LES、全速域隐式推进与三维机翼能力”版本。完成时必须做到：

1. 在现有结构多块、WCNS、CGNS 和 MPI 框架中支持统一的 RANS 附加输运场、壁距、湍流黏度、
   边界条件、输出和可改变 rank 数的重启；`laminar` 路径保持 v1.1.0 行为。
2. 提供至少两个生产支持级的常用湍流模型：`sa_neg` 和明确变体的 `k_omega_sst`；提供标准
   `k_epsilon` 及显式壁面处理接口，证据不足时只能标为实验功能，不能冒充已验证模型。
3. 建立三维可压缩 Favre 滤波 LES，至少包括原始 `smagorinsky`、Bardina
   `scale_similarity`、`mixed_smagorinsky_similarity`、`dynamic_smagorinsky` 和 `wale`，并
   区分结构模型、耗散模型及其能量传递；二维计算明确拒绝 LES。
4. 建立瞬时和时间累计的壁面/边界层统计，包括 `Cp/Cf/y+`、摩擦速度、热流、涡黏度比、
   湍流变量、均值/RMS/协方差、整体与截面载荷，并保证 MPI/restart 一致。
5. 对 Roe 路径实现完整的 Weiss--Smith 型低 Mach 预处理，覆盖特征速度、通量耗散、更新矩阵、
   远场边界和失败回退；定常进入伪时间，非定常进入双时间内迭代，真实物理时间导数保持守恒。
6. 将 LU-SGS 固定为 v2 唯一新增隐式推进算法：定常使用本地伪时间 LU-SGS，非定常使用
   BDF2（BDF1 启动）加双时间 LU-SGS；SSPRK3 只保留为兼容和显式对照。
7. 完成用户提供的 Case06 NACA0012 二维 RANS/URANS 算例计算、数值收敛和可追溯比对。
8. 在用户后续提供目标条件后，完成最终三维翼型/机翼算例，包括 RANS/LES 适用性选择、MPI、
   截面载荷、表面统计、时间统计及网格/模型不确定性说明。
9. 形成内部可复现的 v2.0.0 源码、配置、算法、验收和版本说明；对外发布和许可证继续暂缓，
   不作为本版本卡口。

## 2. 当前基线与缺口

### 2.1 可复用能力

- v1.1.0 已有五分量层流 Navier--Stokes、常黏度/Sutherland、Prandtl、SSPRK3、
  Rusanov/HLLC/Roe、两套 WCNS profile、物理容许性/逐面降阶和整步重试。
- 已有结构多块 CGNS、运行时切分、非阻塞 MPI halo、共享面权威通量、边界真实迹、壁压/牵引/
  热流、`Cp/Cf`、力/力矩和同/异 rank 重启。
- 已有 field/statistic registry、残差历史、平面统计和简单槽道壁统计，可作为扩展接口，但当前
  槽道量只是瞬时空间平均，不能作为湍流时间统计。
- v1.1.0 正式标签为 `v1.1.0`，当前主干基准提交在计划建立时为 `00bb903`；计划冻结时必须
  重新记录实际提交、编译器、MPI 和测试清单。2026-09-12 的计划前只读回归为本机串行
  Release 60/60、Intel MPI Release 108/108 通过，可作为阶段 V 重建基线的参考而非替代证据。
- 2026-09-13 修订计划时另有未跟踪的
  `cases/manual/case05_3d_turbulent_channel/results/lowmach-longrun-segment01/`（16 个文件，
  118,067,120 byte）及 Case06 网格目录；两者均按用户保留输入/结果处理，本次不暂存、不修改。

### 2.2 必须解决的结构缺口

1. `StructuredBlock` 当前只有固定五分量平均流，缺少模型可注册附加场、标量 halo/重构/扩散、
   模型源项和检查点 schema。
2. 黏性通量只使用分子黏度/导热，尚无 Reynolds 应力、湍流热通量和湍动能各向同性项。
3. 没有全局最近壁距；索引层数或局部法向距离不足以支持曲面、多块和三维机翼。
4. 当前 Riemann 接口只接收左右平均流状态和法向，低 Mach 所需参考速度、局部尺度、伪时间
   特征系统与远场边界没有统一上下文。
5. 当前定常停止以残差为主，没有模型残差、力/矩窗口、伪时间局部步和刚性源隐式处理。
6. 当前统计不保存累计权重和二阶矩，不能在重启后继续可靠的均值/RMS/Reynolds 应力。
7. 当前没有离散网格/测试滤波、SGS 应力与热通量、动态系数、能量预算或三维 LES 验证矩阵；
   现有数值耗散也未与 SGS 耗散分离。
8. 当前没有隐式 Jacobian、LU-SGS 前后扫或双时间状态机；SSPRK3 不能直接替代非定常隐式
   时间精度证明。
9. Case06 只有网格，缺少经确认的工况、壁面热条件、湍流远场量和目标数据；单网格也不能单独
   证明网格无关。
10. 最终三维目标算例尚未提供，相关阶段必须允许等待输入而不伪造验收条件。

## 3. 范围边界

### 3.1 必做范围

- Favre 平均可压缩 RANS 基础设施、Boussinesq 线性涡黏性闭合和可配置 $Pr_t$；
- 维数无关的物理壁面距离，支持结构多块、运行时切分和 MPI；
- fully turbulent `sa_neg`；
- 明确且不混用变体的 `k_omega_sst`；
- 标准 `k_epsilon` 和显式 `resolved|wall_function` 接口；若模型验证不足，最终必须显式标为
  experimental，但接口、公式测试和失败边界仍须完成；
- 三维 Favre 滤波 LES、确定性网格/测试滤波、SGS 应力/热流和能量预算；
- `smagorinsky`、`scale_similarity`、`mixed_smagorinsky_similarity`、
  `dynamic_smagorinsky` 和 `wale`；
- turbulence-aware 的边界/初场/远场、标量对流扩散和刚性源处理；
- 定常及非定常 Roe/Weiss--Smith 预处理；
- 定常本地伪时间 LU-SGS，以及非定常 BDF2/BDF1 加双时间 LU-SGS；
- 壁面/时间/截面统计，重启连续性和串并行一致性；
- Case06 和一个用户后续提供的三维翼型/机翼目标算例；
- 本机严格轻量自动验收、服务器大型算例预算验证、阶段人工放行、文档与 Git 证据闭环。

### 3.2 条件增强项

只有核心任务按期过卡且阶段设计另行冻结时才允许进入，不得阻塞或污染核心路径：

- 低 Mach 多重网格、网格序列或更强 Krylov 线性求解；
- 点涡修正远场、自动攻角扫描和 restart continuation；
- `k_epsilon` 的 realizable/RNG 变体；
- Vreman 等更多代数 SGS 模型、Lagrangian 动态平均和显式 SGS 动能方程；
- 更复杂的曲率/旋转修正或 QCR 非线性应力修正；
- HDF5/并行 CGNS、自动网格生成或自动网格自适应。

### 3.3 明确非目标

- DES/DDES、RANS/LES 区域混合、壁模 LES、DNS 专用能力和 Reynolds 应力模型；
- $\gamma-Re_\theta$ 等转捩模型。若 Case06/三维目标要求自然转捩，先修订版本范围；
- 多组分、燃烧、化学反应、真实气体、辐射、共轭换热；
- 非结构/混合/重叠网格、非共形接口、运动/变形网格和 AMR；
- 伴随、气动优化、流固耦合、旋翼运动和完整飞行器自动化；
- 为本地项目重新建立外部 CI、对外发布或替项目负责人作许可证决定。

## 4. v2.0.0 不可破坏契约

1. `turbulence.model=none` 时不分配模型场、不改变平均流残差、时间步、输出顺序或 v1.1.0
   默认配置语义；受影响基线必须逐位或按冻结的舍入容差一致。
2. 模型场与平均流共享块拓扑、owner、halo 版本和接受事务；任何一项非法时整个候选子步/伪
   时间步拒绝，不能提交“平均流新、湍流量旧”的混合状态。
3. 每个湍流模型只有一个权威变体标识、常数表和参考来源；常数、limiter、远场值、壁面处理、
   $Pr_t$ 和轨迹相关 floor 全部进入摘要、manifest 和 restart signature。
4. SA-neg 允许模型定义内的有限负工作变量；`k/omega/epsilon` 必须严格正。容许域策略是检测、
   一致降阶和拒绝，不是无日志裁剪。
5. 全局壁距只由命名物理 wall patch 产生，跨 rank 数/分区保持一致；人工切分面和连接面不算壁。
6. 平均流中的分子/湍流应力和热流只在一个权威黏性通量路径组合，边界统计复用同一物理定义；
   后处理不得再用另一套符号、法向或导数近似。
7. LES 只允许三维非定常计算；滤波权、滤波宽度、边界闭合和动态平均支持跨分区确定，不能
   形成 rank 相关模型。结构相似项允许的反向传递不得被未配置的黏度静默消除。
8. 低 Mach 预处理只改变伪时间和数值耗散，不改变定常方程或非定常物理时间方程；`beta=1`
   必须严格恢复普通 Roe 特征和谱半径。`preconditioner=none` 时保留既有 Riemann 路径。
9. 预处理选择、Riemann、CFL、远场和稳健性回退是一个受验证组合；不支持的组合在初始化前
   一致拒绝，不能静默退化。
10. LU-SGS 是唯一新增隐式算法；定常和双时间内迭代共享权威前/后扫与谱半径实现。非定常
    物理层只有内迭代充分收敛后才可接受，不能把代数误差伪装成物理非定常。
11. 时间统计只累计已接受的完整物理步，保存权重、均值和二阶中心矩；伪迭代、重试、重复事件和输出重读
   不得双计。
12. Case06 和三维目标的“程序可运行”“离散已收敛”“与参考数据一致”是三个不同结论，报告
    必须分别给证据和局限。
13. 任何性能优化不得与模型公式变更混合提交；每项优化必须有前后数值证据和可回退提交。
14. 用户输入文件默认只读；未获明确批准不得移动、改写、格式化、暂存或纳入发行包。

## 6. 每阶段统一执行步骤与卡口

### 6.1 统一步骤

1. **登记基线**：提交号、分支、工作树、用户文件、工具链、硬件、串行/MPI 测试数和性能摘要。
2. **编写设计**：新增 `docs/v2.0.0/stage-<id>-design.md`，列明公式引用、接口、数据所有权、
   边界、失败语义、配置/restart 影响、测试矩阵、阈值和非目标。
3. **人工冻结设计**：涉及数学/范围的更改先更新《算法补充》和本计划。设计未批准不得修改
   该阶段生产 C++。
4. **小提交实现**：公式/接口、实现、测试、文档和性能优化分开提交；每个提交运行最小受影响集。
5. **阶段前验**：使用临时干净构建，运行公式、单元、数值、失败、串行/MPI 和重启专项。
6. **正式自动验收**：从候选提交重新构建，先执行受资源上限约束的 L 级卡口，保存命令、环境、
   原始日志、阈值、结果和哈希到 `docs/v2.0.0/stage-<id>-acceptance.md`；S 级另存服务器预算和状态。
7. **候选与人工判断**：自动全过后创建不可移动的 `v2.0.0-<id>-candidate.N`，停下供人工检查。
8. **批准后合并**：记录批准提交/日期，可加 `approved.N` 标签，以 `--no-ff` 合入
   `release/v2.0.0`；要求修改则保留旧候选并递增编号重验。

前置 AA 是一次已批准的依赖顺序例外，但不取消上述卡口。AA 候选因包含尚未结项的 X-A 基线，
自动通过后按连续授权只回合到 `stage/v2.0.0-x`，不得单独合入 `release/v2.0.0`；待 X-B 全部
自动卡口通过后，由 X 的非快进合并一次性把分别留有候选和自动证据的 X 与 AA 纳入 release，
随后建立 Y。Y 自动通过并形成候选后停止等待人工验收；Z 不在本次连续授权内。

## 19. v2.0.0 完成定义

只有同时满足以下条件才能称为完成：

1. V--AE 全部阶段有设计、自动报告、不可移动候选和人工批准记录；
2. v1.1 laminar/Euler 兼容路径全回归，所有本机 L 级串行/MPI Release 卡口通过；
3. SA-neg 与 SST 达生产支持级，k-epsilon 的实际支持级别与证据/文档一致；
4. Smagorinsky、尺度相似、混合、动态 Smagorinsky 和 WALE 通过三维滤波、能量/频谱、槽道及
   MPI/restart 验收，实际支持等级与证据一致；
5. 壁距、RANS/SGS 应力与热流、模型输运、边界、输出和同/异 rank 重启一致；
6. LU-SGS 同时通过定常解一致性和非定常 BDF2/双时间二阶精度；低 Mach 预处理覆盖矩阵、
   通量、谱半径、伪时间、物理时间、远场和回退，证明渐近正确与真实加速；
7. 壁面/时间/截面统计定义、抽样、checkpoint 和 MPI 加和可审计，LES 数值耗散与 SGS 贡献分离；
8. Case06 和用户目标三维翼型在服务器预算内完成并获人工接受，且分别说明收敛、离散、时间、
   模型、参考和资源不确定性；
9. 配置、算法、用户/开发手册、限制、版本说明、安装树和内部源码包与实现一致；
10. `v2.0.0-rc.N` 在合并主干前通过最后人工核验，之后才创建正式标签并同步远程；
11. 外部 CI、对外发布和许可证仍按项目负责人当前决定暂缓，不被文档暗示为已完成。
