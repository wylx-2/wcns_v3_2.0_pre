初始化关键数值（16³ 单独验收）：

- 解析谱 A=0.00013、k₀=8：目标 K₀=0.500523533878318，与物理场和独立 DFT 的能量一致至浮点舍入误差。
- 独立 NumPy DFT 检查了零模态、球形截断、k·û=0、Parseval 关系和逐模态目标；CBC 重匹配模态能量的最大相对误差为 1.926994704620247e-15。
- 重匹配后的每个横向模态均为演化前对应横向模态乘一个正实数，验证没有重新随机化相位；各点 ρ、p、T 的差小于 2e-12。
- 准备阶段统计权重恒为零；正式初始时间/步数/统计权重均为零。
- 准备中、准备终点、正式 step=0 三种位置的 strict 重启全部通过。正式检查点续算没有重新创建准备目录。
- 新解析谱 MPI 4 与串行的最终导出场差为 0；准备路线 MPI 4 的最大缩放场差为 1.1879386363489175e-14；准备中检查点重分区到 MPI 2 的最终场差为 0。
- 旧 HIT 的最大回归差为约 1.76e-12（单区网格自动切分为 4 进程），满足测试的舍入误差容差。

非法配置检查包括：未知初始化名称、A≤0、解析谱与 `hit.initial_energy` 冲突、解析谱开启 CBC 准备、强迫流开启 CBC 准备、strict 续算修改准备时长或 A、准备路线使用 algorithm_change。

## 有效范围

新增验收中准备时长仅为 0.001（程序无量纲时间，16³ 时 3 步）；正式阶段最多 2 步，交付 smoke 配置最多 3 步。**没有执行正式 CBC 的 0.10381382891686522 准备阶段，也没有进行测站间长衰减或统计收敛计算。** 测试验证实现一致性，不能证明已形成成熟湍流，或 ILES 与实验/DNS 已达到某种误差水平。

32³、128³新解析谱网格与此前已交付并验证的 2π 周期八块网格逐字节一致，SHA-256 已记录；本次未对它们做时间推进。正式示例仍采用常黏度；与论文输运定律及统计定义的差别见 [初始化说明](HIT初始化与预演化说明.md)。

## 可复核证据与命令

本目录的 `initialization-validation.json` 保存成功运行的新增验收、旧回归、示例检查、旧版本兼容性和网格 SHA-256；`initialization-sources.json` 保存参考材料身份与核对位置。详细日志留在 `tmp/hit-init-20261007/`。

```sh
python tests/test_hit_initialization.py --runner build/wcns_run --repository . --work /new/empty/acceptance --mpiexec /path/to/mpiexec
python tests/test_hit_runtime.py --runner build/wcns_run --repository . --work /new/legacy --mpiexec /path/to/mpiexec --generator build/wcns_generate_hit_cgns
ctest --test-dir build -R '^wcns\.(unit|hit|slab_fft(\.mpi[34])?|chapter5|periodic_hill)$' --output-on-failure
```

新增 Python 验收脚本需要 NumPy；求解器本身不依赖 Python。各短测允许正常以退出码 2 达到步数上限，非法输入预期退出码 1，dry-run 预期退出码 0。物理计算是否完成以日志 stop reason 和终止时间判断。
