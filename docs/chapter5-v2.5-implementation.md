# WCNS v2.5：第五章算例使用与统计定义

本版本在现有 v2.4 工作区基础上新增 SD7003 和 24° 压缩拐角。源码版本 2.5.0，程序标签 2.5；未更改 Git 历史。周期山及已有用户工作保留。研究依据见 [调研报告](chapter5-v2.5-research.md)，实测验证范围见 [验证记录](v2.5-validation.md)。

## 1. 文件和构建

源码包 `WCNS_v2.5`；另附 `WCNS_v2.5_SD7003_case`、`WCNS_v2.5_compression_ramp_case`。每个包都有 SHA-256 清单。源码含内置 CGNS；不依赖商业网格软件。服务器需要 CMake≥3.20、兼容本项目的 C++20 编译器和 MPI 开发环境：

```bash
cd WCNS_v2.5
sha256sum -c PACKAGE_CONTENTS.sha256
cmake -S . -B build-mpi -DCMAKE_BUILD_TYPE=Release -DWCNS_ENABLE_MPI=ON -DWCNS_ENABLE_CGNS=ON -DWCNS_BUILD_TESTS=OFF
cmake --build build-mpi --parallel 4
```

后处理/重新生成二维网格另需 Python、NumPy≥2.0、SciPy、Matplotlib、Pillow。正常求解直接读已交付 CGNS，无需 Python。包内没有 Windows 编译缓存；在服务器重新编译。

进入算例目录后，设置可执行文件路径，例如：

```bash
export WCNS_RUN=../WCNS_v2.5/build-mpi/wcns_run
mpiexec -n 4 "$WCNS_RUN" --config smoke.wcns --dry-run
mpiexec -n 4 "$WCNS_RUN" --config smoke.wcns
```

`smoke.wcns` 最多 3 个接受步，墙钟上限 120 秒；时间上限检查在步间进行，不是强制中断单步。`maximum_steps` 正常返回码为 2，配置错误为 1，数值失败为 3。输出目录默认禁止覆盖；重测请改为新目录。SD7003 smoke 保留二维节点，只把展向从 40 减到 8（344064 单元）；拐角 smoke 为 12×8×24×8（18432 单元），仅用于功能检查，不能用于物理结论。

服务器生产命令将配置改为 `production.wcns`。**本机不执行该长计算。** 生产 dry-run 仍分配流场并建立度量，不是轻量的配置解析；需先确认服务器内存。两例最终生产网格已按原生块逐块进行了几何审计，未在本机做全网格流场推进。

程序按配置所在目录解析 mesh/restart 路径，按启动工作目录解析 output.directory；因此始终在算例目录启动。`production_restart.wcns` 指向前段 `*.checkpoint.latest.cgns`，输出进入新目录。继续推进时适当提高 t_end；统计截止时间不变时，超过截止时间不会继续累计。

## 2. 算例设置与补充选择

两例均为三维黏性、无湍流/SGS/壁面模型、无 Weiss–Smith 预条件。保留现有鲁棒性重算机制，使用已接受的物理步进行统计。SD7003 参数固定为 Ma=0.2、Re=60000、4°，绝热静止壁；初始化在局部叠加幅值 10⁻⁴ 的展向速度扰动以打破严格二维对称，远场不持续注入湍流。该初始扰动不等同于实验 Tu。

拐角参数固定为 Ma=2.25、Re=15800、γ=1.4、Pr=0.72、S/T∞=110.4/170、Tw/T∞=323/170。层流入口由压缩性 Dorodnitsyn 相似方程边值问题生成，δ99=δ₀；表有 1025 个等距 y 点，运行时线性插值，外缘归一化 ρT=1。生成方程、求解容差、表值及数值残差保存在 `generate_ramp_inlet.py`、`inlet_similarity.csv/json`，非手填经验速度多项式。初始化将该剖面沿局部壁面平移/旋转，尚无平衡激波，启动流动需要充分排除。

体力仅在 2.33<x<2.67、0<y<0.01 生效，单位为 ρ_ref U_ref²/L_ref：

`Fx = -A sin²[π(x-2.33)/0.34] sin²(πy/0.01) × {1+0.2 sin(6πz/Lz+2π·0.7t)+0.2 sin(14πz/Lz-2π·1.1t)}`。

默认 A=5、Lz=6，其他动量源为零，能量源为 uFx。该周期反向体力是明确记录的工程适配；文档未提供其原始幅值和波形。不可宣称与 Porter–Poggie 的转捩激励完全相同。涡量/应力和入口发展诊断应在服务器先通过。

流场、网格、统计均以 L_ref、U_ref、ρ_ref、T_ref 无量纲化。SD7003 L_ref=c；拐角 L_ref=δ₀。配置使用 ρ_ref=1，并由目标 Re 设置 μ_ref；这是等价无量纲工况的尺度选择，**不是**前期论文 p∞=23830 Pa 的完整量纲空气状态。若要按该压力输出量纲值，需一起设 ρ_ref=p∞/(RT∞)、μ_ref=ρ_ref U_ref L_ref/Re，保留 Ma/Re 与 S/T∞。当前新模块 CSV 始终无量纲，不随 `output.dimensional` 改变。

## 3. 输出与计算定义

新模块由 `benchmark.type=sd7003|compression_ramp` 打开，只对配套的均匀展向挤出、多块沿 i 分区、各原生块 jmin 为静止壁面的几何启用；不应随意用于任意拓扑。MPI 可以重新分配原生块，运行时可继续细分，壁面子块必须容纳完整壁面模板。配套配置保留最少 6 个活动方向单元。

| 输出 | 内容 |
|---|---|
| `*_benchmark_mean_xy.csv` | x/y 上的 ρ、u/v/w、p、T；6 个 Reynolds 和 6 个 Favre 应力；Favre 速度；ρ/p/T RMS；累计权重与样本数 |
| `*_benchmark_wall.csv` | 壁坐标、方向、长度、p/Cp、p RMS、带符号 τt/Cft/Cfx、τz、热流及 RMS、Tw、ρw、uτ、y+、反向流动比例、μw/Re、首层距离 |
| `*_benchmark_history.csv` | 接受步时间、升阻力/力矩、瞬时展向平均壁面 Cf 的最长闭合分离区间 xs/xr、壁压梯度位置和最大热流 |
| `*_benchmark_loads.csv` | 时间平均升阻力与力矩、RMS、累计时长 |
| `*_benchmark_probes.csv` | 固定三维最近单元探针的实际 x/y/z、ρ/u/v/w/p/T；无空间插值 |
| CGNS 场 | ρ、u/v/w、p、T、Mach、Q、三个涡量分量 |

权重为每个接受步与统计窗重叠的 Δt，场值取接受步末状态；每个二维位置先累加展向原始一/二阶矩，再做时间累加。Reynolds 应力为 〈uiuj〉−〈ui〉〈uj〉；Favre 应力为 〈ρuiuj〉/〈ρ〉−ũiũj。这保留展向脉动，不是对展向平均速度求方差。RMS 包含时间和展向变化；载荷 RMS 则是展向积分载荷的时间波动。

Cp=(〈pw〉−p∞)/(ρ∞U∞²/2)，Cft=〈τt〉/(ρ∞U∞²/2)，Cfx=Cft tx。切向量取局部朝下游的方向；SD7003 上下表面分别输出。壁面压力/温度采用求解器的边界插值，速度和等温壁温度导数采用相同 4/6 点 Dirichlet 模板与首层物理距离映射。修复了曲壁 SCMM 单元中心与直线面心混用导致负壁距的问题，已有平板、周期山和黏性求解器测试通过。

`q_into_wall` 以 ρ_ref U_ref³ 为单位，正值表示热量流入固体；绝热翼型为零。uτ=sqrt(|τ向量|/ρw)，y+=ρw uτ d1/(μw/Re)。CSV 的 uτ/y+ 是瞬时值的平均，后处理另给由平均 τt 定义的摩擦速度，两者不必相同。SD7003 载荷按单位展宽和 c 归一化，再旋转到来流坐标；Cmz 绕 (0.25c,0)，正值遵守右手定则。拐角全壁力仅作积分诊断。

此模块的二维载荷采用压力加切向壁面摩擦的积分，未加入黏性法向应力；比较高精度压缩性总牵引时应保留这一离散诊断限制，不能把它称为所有应力分量的精确面积积分。

历史中的 xs/xr 是指定范围内、展向平均瞬时 Cf 有两次符号穿越的最长闭合负区间；没有可识别区间时输出 NaN，不强行指定位置。`wall_pressure_gradient_x` 是 75<x/δ₀<125 内最大正壁压梯度位置，仅为激波相关运动的代理量；激波脚形态仍应结合瞬时压力/密度梯度检查，不能与原文所有激波定义等同。

Q=½(||Ω||²−||S||²)，涡量=∇×u；使用坐标感知的局部差分诊断，块边缘单边差分。它们不是修改求解器通量的项，也不宣称与高阶残差相同阶数；用于文档 Q=24 的定性可视化。

## 4. 后处理与验证流程

从各算例目录执行（服务器完成有意义的统计后）：

```bash
python tools/analyze_chapter5.py --case sd7003 --prefix output/sd7003-production/sd7003-iles --output analysis --start 20 --span-cells 40 --reference reference
# 拐角相应使用：--case ramp --prefix output/ramp-production/ramp-iles --start 1000 --span-cells 72
```

脚本输出壁法向速度/应力和 Van Driest 剖面、δ99/δ995、可压缩位移/动量厚度及 H、Δx+/Δz+、Cf 零点、SD7003 转捩阈值诊断、热流系数、探针/载荷/分离位置 PSD、探针压力相干和八段时间均值。SD7003 的剖面位置为 x/c=0.1、0.5、0.95；拐角为 x/δ₀=70、80、90、100、110、120、130。采用显式结构三角剖分沿壁法向插值，避免跨固体插值。

边界层外缘参考暂取 n/c=0.2 或 n/δ₀=5 处；强相互作用中需检查是否真在边界层外。转捩指标为 n/c≤0.1 内 max(−〈u′v′〉)>0.001 持续至少三个相邻壁面列，是可复现的阈值诊断，不是唯一转捩定义。位置、网格分辨率和阈值敏感性应一起报告。

固定探针目前是预置笛卡尔坐标。文档的“当地平均边界层厚度一半”只有得到 pilot 平均剖面后才能确定；读取 `boundary_layer.csv` 后调整探针，用新的统计段记录，不能把当前默认探针称为论文精确位置。时间谱先以最大采样间隔线性重采样，再用 Hann/Welch、50% 重叠；少于 128 点不计算，超过中位间隔两倍的缺口拒绝拼接。实际频率分辨率、Nyquist 频率和时长写入 JSON；频率 fL_ref/U_ref，比较拐角 fLsep/U∞ 时须乘收敛的 Lsep/L_ref。更改历史输出频率后应重新检查混叠。

`wall_heat.csv` 给出 Cq=q/(ρ∞U∞³/2) 和按自由来流恢复温度定义的 St；此工况 Tw 接近自由来流恢复温度，St 分母较小，定量比较优先明确热流及所用恢复温度。压力相干仅表示所选固定点关系，不自动等于因果关系。八段标准误差只有分段长度远大于积分相关时间才可信。

`--reference reference` 可生成 Cp/Cf 误差 CSV 和叠图。SD7003 Cp 以两表面中较近者匹配，前/尾缘须人工核对；误差包含读图误差，不作为严格真解误差。速度剖面参考 CSV 与输出 `profiles.csv` 用相同站位、切向速度和法向距离比较。

严格续算恢复原始累计矩、时间权重、计数和上一采样时刻。统计窗/探针身份不一致则拒绝。`restart.mode=algorithm_change` 会按现有机制重置统计；可用于 pilot 后开新统计段，但新窗必须处于恢复时刻之后。不同段的瞬时 history/probes 应按时间合并、核对重复时间与缺口；**不要简单平均两个累计 mean 文件**，续算后的累计文件已包含前段权重。

## 5. 修改边界与剩余验证

新增模块集中在 `physics/chapter5.hpp`、入口表、`runtime/chapter5.*`，以及既有配置、初始化、源项、入口、检查点和输出注册表中的接线。唯一针对原壁面核心的必要修复是曲壁一致壁距；没有重写空间离散或引入湍流模型。生成工具写共形结构 CGNS，不导入论文非结构网格。

本机测试确认代码和数据路径可运行，尚未证明粗网格 ILES 的转捩位置、气动力、激波位置、热流峰值或长时间频谱精度。先在服务器评估 SD7003 的显式步长成本，核查拐角入射湍流边界层，随后分段推进并比较独立时间窗；最后才进行网格/耗散/展宽敏感性研究。
