# WCNS v2.0_pre

WCNS 是面向二维/三维结构多块网格的高阶可压缩流动求解程序。`v2.0_pre` 集成 RANS、LES、
低马赫预处理、定常/非定常 LU-SGS、壁面/载荷输出和可重启加权统计，是功能完整但物理验证
受限的内部前瞻源码版本。

本目录只包含程序源码、离线构建依赖和必要文档，不包含算例、网格、测试、运行结果或构建树。
大型 Case06、长期湍流及目标三维翼型没有在该版本中执行，因此不能从版本名称推断工程精度。

## 构建

需要 CMake 3.20 以上和支持 C++20 的编译器。固定的 CGNS 4.4.0 源码归档已包含在
`third_party/cgns/`，默认不需要联网。

串行 Release：

```text
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
cmake --install build --prefix install
```

MPI Release：

```text
cmake -S . -B build-mpi -DCMAKE_BUILD_TYPE=Release -DWCNS_ENABLE_MPI=ON
cmake --build build-mpi --parallel 2
cmake --install build-mpi --prefix install-mpi
```

精简目录不带开发测试。`WCNS_BUILD_TESTS` 默认关闭；完整自动测试保存在开发仓库对应来源提交中。
小型示例和算例模板也不随包提供，`WCNS_INSTALL_EXAMPLES` 默认关闭。

## 使用

先检查用户自己的 CGNS 和配置：

```text
install/bin/wcns_inspect_structured_mesh <mesh.cgns>
install/bin/wcns_run --config <case.wcns> --dry-run
```

确认摘要、网格签名、分区、模型、时间推进、参考量和输出目录后再运行。首次使用 RANS/LES、
低马赫或统计功能前，应阅读用户手册对应章节和已知限制。

## 完整性与许可

`WCNS_SOURCE_REVISION` 记录开发仓库来源，`PACKAGE_CONTENTS.sha256` 列出目录中每个普通文件的
SHA-256。WCNS 自有代码尚未选择对外许可证，本目录仅供内部使用；第三方 CGNS 使用其独立
许可证，详见 `LICENSE.md` 和 `THIRD_PARTY_NOTICES.md`。
