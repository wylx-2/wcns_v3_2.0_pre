# WCNS v2.6

新增三维均匀各向同性自由衰减与强迫湍流，采用无显式湍流模型的粗网格 ILES。保留 v2.5 已有算例功能。

## 构建

需要 CMake 3.20 及以上、C++17 编译器和 MPI 开发环境。FFTW 3.3.11 与 CGNS 4.4.0 源码归档随包保存，无需在线下载。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DWCNS_ENABLE_MPI=ON -DWCNS_ENABLE_FFTW=ON
cmake --build build -j --target wcns_run wcns_generate_hit_cgns
```

MPI 分布 FFT 采用 WCNS 自有 slab 转置和 FFTW 本地一维变换，不依赖 libfftw3_mpi。关闭 WCNS_ENABLE_FFTW 可用内置 radix-2 后端。两种后端均经过1、3、4进程 FFT 测试。当前并行运行仍需要安装目标平台的 MPI 运行环境。

## 算例与报告

两个独立算例包为 `WCNS_v2.6_HIT_decay_case` 与 `WCNS_v2.6_HIT_forced_case`，各含16³、32³、64³、128³八块网格、配置、原始参考数据和工具。`smoke.wcns` 最多运行3步；正式配置用于服务器。

```sh
cd ../WCNS_v2.6_HIT_decay_case
mpiexec -n 4 ../WCNS_v2.6/build/wcns_run --config smoke.wcns
```

冒烟测试正常以 max_steps 停止时返回码为2；查看停止原因。程序默认拒绝覆盖已有输出目录。相对输出路径以启动工作目录为基准，运行前先进入算例目录。下方源码测试命令需回到 WCNS_v2.6 源码目录执行。

详细研究、数学约定、统计定义与服务器步骤见 [HIT 报告](docs/hit-v2.6/HIT算例与v2.6实现报告.md)。新增源码为 `src/runtime/hit.cpp` 与 `src/parallel/slab_fft.cpp`，网格工具为 `tools/generate_hit_cgns.cpp`。FFTW 许可见 [第三方通知](THIRD_PARTY_NOTICES.md)。

## 测试与范围

```sh
cmake -S . -B build -DWCNS_ENABLE_MPI=ON -DWCNS_BUILD_TESTS=ON
cmake --build build -j --target wcns_hit_tests wcns_slab_fft_tests wcns_unit_tests wcns_periodic_hill_tests wcns_chapter5_tests
ctest --test-dir build -R 'wcns\.(hit|slab_fft|unit$|periodic_hill$|chapter5$)' --output-on-failure
```

本机只完成解析、配置和短步检查，没有进行长期物理统计验证。详见 `package-validation.txt`。全局统计、能谱和两点相关函数保存在算例输出中；HIT 空间相关函数目前只沿 x 分离，不是全方向相关张量。

源码包是工作目录的明确版本快照，`WCNS_SOURCE_REVISION` 标识其基线提交，`PACKAGE_CONTENTS.sha256` 校验实际交付文件。它不需要提交或修改使用者原有 Git 工作区。
