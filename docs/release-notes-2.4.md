# WCNS v2.4

在 v2.3 上增加论文第 5.3.4 节 Re_h=1400、Ma_b=0.1 周期山 ILES 支持，保留原求解器离散流程。

- 新增标准周期山初场与 ADF-CGNS 网格生成器。
- 新增山顶截面流量反馈；现有压力梯度源项获得更新接口，动量和能量一致更新。
- 新增时间／展向均值、Reynolds 应力、四个剖面、壁面剪切及 Cf。
- 控制器和统计状态写入 `WCNS_PeriodicHill`，支持串行/MPI重分区严格续算。
- 关闭新模块时保留旧配置、数值路径和重启签名；版本标签为 2.4。

物理设置、论文未披露参数及限制见 [周期山报告](periodic-hill-v2.4.md)，短步测试见 [验收记录](v2.4-validation.md)。本版本不宣称完成长时间湍流验证。
