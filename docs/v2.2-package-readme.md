# WCNS v2.2 Linux 源码包

本目录是从受控 Git 提交生成的精简 Linux 源码包，只包含程序源码、CMake、内置 CGNS 源码、
必要工具、文档和 t=250 配置模板；不包含测试、网格、算例结果或开发中间文件。

先核验完整性：

```bash
sha256sum -c PACKAGE_CONTENTS.sha256
cat WCNS_SOURCE_REVISION
```

串行构建：

```bash
cmake -S . -B build-serial \
  -DCMAKE_BUILD_TYPE=Release \
  -DWCNS_ENABLE_CGNS=ON \
  -DWCNS_ENABLE_MPI=OFF \
  -DWCNS_BUILD_TESTS=OFF
cmake --build build-serial --parallel 4
cmake --install build-serial --prefix install/serial
```

MPI 构建：

```bash
cmake -S . -B build-mpi \
  -DCMAKE_BUILD_TYPE=Release \
  -DWCNS_ENABLE_CGNS=ON \
  -DWCNS_ENABLE_MPI=ON \
  -DWCNS_BUILD_TESTS=OFF
cmake --build build-mpi --parallel 4
cmake --install build-mpi --prefix install/mpi
```

v2.2 内置 Riemann 求解器为：

```text
rusanov | hll | hllc | roe | roe_all_speed |
roe_all_speed_rieper | roe_rotated
```

Li--Gu all-speed Roe 的完整配置为：

```text
algorithm.riemann = roe_all_speed
algorithm.roe_all_speed.reference_mach = 0.1
algorithm.roe_all_speed.dissipation_scale = 0.02
algorithm.roe_all_speed.pressure_coefficient = 0.05
time.integrator = ssprk3
preconditioner.type = none
```

使用自备网格和配置时，必须先执行 `wcns_run --config case.wcns --dry-run`。从 v2.1
`roe_all_speed` checkpoint 切换到 v2.2 同名 Li--Gu 算法时使用
`restart.mode=algorithm_change`；复现旧算法则选择 `roe_all_speed_rieper`。

详细操作见 `docs/linux-server-guide.md`，算法和配置见 `docs/riemann-solvers-v2.2.md`、
`docs/all-speed-roe.md` 与 `docs/config-reference-2.md`。本包未附带大型物理验证结果，也不代表
程序已完成 Case06 或三维翼型服务器验收。
