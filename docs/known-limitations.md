# WCNS v1.1.0 与 v2.0.0 阶段 Z 已知限制

这些限制是当前实现边界，不应通过静默降阶、占位零值或忽略配置来规避。

## 物理与数值模型

- 仅支持单组分、热完全理想气体和常数比热比。v2 分支已实现 SA-neg、modified SST-2003m
  和显式实验级标准 k-epsilon，但本机 L 级自动证据不能代替 TMR 细网格/槽道/hump 的服务器
  S 级物理验证；Case06 NACA0012 已冻结 TMR 工况并进入 AB-L，但 897×257 的服务器 S 级
  物理收敛仍待完整 v2 功能完成后执行。
- schema 2 已实现定常 LU-SGS 以及非定常 BDF2/BDF1 双时间 LU-SGS；没有多重网格、Krylov
  或通用全隐式 Newton。并行前后扫的收敛轨迹可随分区改变，要求的是冻结停止判据和最终物理
  一致性，而不是每次内迭代逐位相等。
- Weiss--Smith 低 Mach 预处理首版只支持 Roe+LU-SGS，并只进入伪时间系统；Rusanov/HLLC
  没有预处理版本。微型渐近/解析门禁不能替代大型低 Mach 外流的独立物理验证。
- 严格配置支持常黏度或 Sutherland 以及正 Prandtl 数；默认仍是 `Pr=0.72`、
  `mu/mu_ref=1` 的常黏度。RANS 与 LES 可提供模型应力/热流；尚无其他温度相关物性、变比热、
  Reynolds 应力模型、DES/DDES 或壁模 LES。
- LES 只支持三维、黏性、非定常 BDF2 双时间 LU-SGS。已实现原始 Smagorinsky、尺度相似、
  混合/动态 Smagorinsky 和 WALE；本机证据限于公式、解析滤波、受限 Taylor--Green、边界、
  重启和 1/2/4-rank 离散卡口。完整 HIT/槽道、能谱、数值耗散反推和长时间统计仍为服务器
  S 级 `pending`。van-Driest 名称会被识别，但在生产 wall-$y^+$ 场接入每次残差前明确拒绝。
- 源项仅包括均匀守恒源、体力和当前制造源；没有通用表达式解释器或运行时动态源项插件。
- v1.1.0 已给出黏性制造解空间收敛和 SSPRK3 时间收敛证据，并用分类扫描覆盖代表性 CFL；
  这些结果不是对任意网格、状态或激波问题的稳定 CFL 上界。配置中的默认 CFL 仍不构成保证。

## 网格、边界与并行

- 只读取二维/三维结构 CGNS zone、顶点坐标、顶点定位的 `PointRange` 物理边界和共形
  `GridConnectivity1to1`；不支持非结构、混合、重叠、滑移接口、AMR 或运动网格。
- 支持常 Z 平面的 `CellDimension=2, PhysicalDimension=3`、reciprocal 同 zone 自连接，
  以及在 NASA TMR C-grid 上已回归的“同一块面部分为物理壁面、部分为尾迹自连接”。
  该回归只覆盖共形 `GridConnectivity1to1`，不扩展到非匹配、重叠或滑移接口。
- 随附 CGNS 以 ADF 后端构建，不能读取仅有 HDF5 后端才能打开的 CGNS 文件。
- 物理边界 ghost 只保证由边界条件构造的原始量及相应守恒量有效。边/角 ghost 不填充，
  ghost 坐标、度量、梯度和其他派生量均不得读取。
- 自动分区是确定性的递归二分，不是图划分器；它以单元数负载为目标，尚不计连接通信量、
  边界类型或异构硬件代价。过窄块会按 profile 模板下限明确拒绝。
- halo 通信使用 MPI，但当前计算/通信没有系统性重叠。CGNS 读写和原 zone 输出重组也不是
  并行 I/O；T 阶段只验证到单机 8 rank，大规模多节点启动、检查点和输出扩展性尚未验证。
  单机弱扩展受内存带宽和进程固定开销影响，仅记录结果而未设置误导性的硬效率阈值。

## 输入、输出与扩展

- 配置仍采用平面 `key=value` 文本；schema 1 保持兼容，schema 2 支持当前 RANS/LES、
  SSPRK3/LU-SGS 与 `none|weiss_smith` 合法组合。`sa_neg` 不支持 trip 或压缩修正，标准
  k-epsilon 只以显式实验开关配 wall function。没有 YAML/JSON、单位系统或表达式。
- CGNS/Tecplot 体场只输出 cell-center 量。涡量、散度和 Q 判据尚未成为内建字段；请求
  未知量会失败，不会输出占位值。v1.1 的边界事件可输出真实面 `q_wall`、`Cp/Cf`、牵引及
  积分载荷，但只适用于已支持的结构物理边界，不是任意浸入面或插值曲面工具。程序另有专用于三维平面
  x-z 等温 J 壁的平均流向剪切、摩擦速度和 `Re_tau` 统计，但它不是通用任意壁面场输出。
- 标准程序已内建总量积分和可选的多层 x-z 平面平均速度/质量积分；其他自定义字段和统计量
  仍需在 C++ 启动装配处注册并重新编译，标准程序不加载动态插件。x-z 统计只接受几何上
  共面的原 zone 单元 J 层，不是任意切面、插值切面或穿过该面的法向通量。
  内建 y-z 截面可按目标 x 坐标监测面积平均 u 和真实 x 向质量流量，但只接受几何常 x
  平面，不支持曲面追踪或插值切片。
- schema 2 已内建按接受物理步 `accepted_dt` 加权的 mean/RMS、全部唯一量对 covariance 和
  Favre 版本，并可随 checkpoint 异 rank 续算；当前仍没有恒流量闭环驱动、自相关误差估计或
  自动平稳性判定。`Re_tau=180`、`Ma_b=0.1` 的 36×48×36 case05 仍只是迁移前可行性网格，
  不是定量 DNS/LES 分辨率。
- 三维边界可按显式右手 span 方向作面心载荷分箱；跨箱物理面不会几何切割，所以箱边界应与
  网格截面对齐。任意曲面截取、非匹配切片和高阶部分面积分配尚未实现。
- 检查点是 WCNS 内部 CGNS 布局，只承诺相同网格与数值签名下跨合法 rank/叶块划分恢复，
  不承诺与其他 CFD 软件互换。
- 当前二进制没有稳定的 WCNS 库 ABI/API 承诺；安装目标面向运行程序和验证工具。由于上游
  CGNS 4.4.0 自带的 CMake install 规则，安装树还会包含 CGNS 静态库、头文件和命令行工具；
  这些文件保持 CGNS 自身的接口和许可证，不代表 WCNS 提供链接兼容性承诺。

经典双马赫反射的专用边界仅适用于二维、`gamma=1.4`、无粘且无源的标准布置：左边界、
下边界和上边界必须显式标记为 `double_mach_reflection`，右边界使用普通流出。它不是可用于
任意激波角度、来流 Mach 数或任意边界方向的通用移动激波边界模型。

## 发布与平台

- v1.1.0 的本机实测环境为 Windows 11、CMake 3.28、MinGW-w64 GCC 8.1、本机 Python
  工具链和 Intel MPI 2021.10。本项目不配置外部 CI；Linux GCC/Clang、OpenMPI、
  ASan/UBSan 及其他未执行的外部平台组合属于未验证，而不是已知不兼容。
- MinGW 构建的程序运行时需要相容的 `libgcc_s_sjlj-1.dll` 和 `libstdc++-6.dll`；MPI 版本
  还需要 Intel MPI 的 `impi.dll` 及运行环境。`cmake --install` 不复制这些工具链运行库。
- WCNS 自有代码尚未选择对外许可证，因此 v1.1.0 源码和二进制仅供本机及内部使用，暂不
  对外发布，也不应作为可自由再分发的开源发行版；见
  [`LICENSE.md`](../LICENSE.md)。
