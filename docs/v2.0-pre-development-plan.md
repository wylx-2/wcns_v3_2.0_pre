# WCNS v2.0_pre 前瞻发布计划

状态：**2026-09-26 起执行。`v2.0_pre` 是功能完整、证据受限的内部前瞻源码版本；它不要求
Case06 大网格、长期湍流算例或用户目标三维翼型的物理验证。所有发布前执行证据限定为本机
公式、单元、制造解和微型二维/三维算例。**

本计划取代原 `v2.0.0` 的 AC--AE 执行顺序，但不删除既有代码、算法规格或历史验收记录。
原计划中的大型服务器 S 级任务转为正式 `v2.0.0` 的后续物理确认项，不再阻塞
`v2.0_pre` 源码目录形成。

## 1. 版本目标

`v2.0_pre` 必须包含原 v2 路线已经规划的通用程序能力：

1. 二维/三维结构多块 CGNS、共形连接、MPI 自动切分和跨合法 rank 重启；
2. Euler、层流 Navier--Stokes、SA-neg、modified SST-2003m，以及明确标为实验性的标准
   高 Reynolds 数 k--epsilon；
3. 原始 Smagorinsky、尺度相似、混合 Smagorinsky--相似、动态 Smagorinsky 和 WALE；
4. Roe/Rusanov/HLLC，Weiss--Smith 低 Mach 预处理及其 Roe+LU-SGS 合法组合；
5. SSPRK3、定常 LU-SGS、非定常 BDF2/BDF1 双时间 LU-SGS；
6. 壁面 `Cp/Cf/q_wall/u_tau/y+`、压力/黏性/总载荷、三轴力矩和三维展向分箱；
7. RANS/LES 模型场与源项诊断、SGS 应力/热流/能量传递和动态系数；
8. 接受物理步加权的 Reynolds/Favre mean、RMS、covariance，统计 checkpoint 与异 rank
   续算，以及现有 x-z、y-z、槽道壁面和截面统计；
9. 严格配置、失败路径、预算上限、输出 manifest 和安装后运行能力。

“功能完整”表示相应代码路径、公式、配置、输出、重启和小规模执行门禁齐备；不表示已经证明
任意工程算例的网格无关性、长期统计充分性或实验精度。

## 2. 本版本明确不做的工作

- 不运行 Case06 897×257、TMR 细网格族、长期 HIT/槽道/hump 或其他大型算例；
- 不运行、缩小代替或宣称验证尚未提供的目标三维翼型/机翼算例；
- 不设置依赖大型物理结果的 `CL/CD/Cp/Cf` 精度阈值；
- 不恢复外部 CI，不进行对外发布，不解决 WCNS 自有代码许可证；
- 不把短步、dry-run 或解析微型场描述为湍流模型的生产物理验证。

这些项目保留在正式 `v2.0.0` 的后续验证清单中，但不属于 `v2.0_pre` 完成条件。

## 3. 本机资源边界

| 项目 | 硬限制 |
|---|---|
| 单个可执行算例 | 不超过 65,536 cells；优先不超过 4,096 cells |
| 单个 smoke | 不超过 20 accepted steps、300 s |
| MPI | serial/2/4 ranks；8 ranks 只保留已有极小通信测试 |
| 原始 Case06 897×257 | 只读哈希、检查和 dry-run；0 时间步 |
| 并发 | 完整 MPI CTest 使用 `-j 1` |
| 发布目录 | 不包含 `cases/`、`examples/`、测试、运行结果、构建树或下载缓存 |

任何门禁超出限制即停止，不以延长本机计算代替代码/公式检查。

## 4. 连续执行阶段

### PRE-A：版本重基线和功能审计

- 从 `v2.0.0-ab-candidate.1` 建立独立 `release/v2.0-pre`，不改写原 release/main；
- 固定 CMake 数字版本 `2.0.0`、程序显示版本 `2.0_pre`；
- 逐项把原 V--AC 功能映射到生产源、配置、测试和算法文档；
- 把大型 S 级证据从前瞻版完成定义移出，并保留准确限制。

自动卡口：版本字符串一致；不存在宣称大型物理验证已通过的文档；`git diff --check` 通过。

### PRE-B：三维与统计支持闭环

- 用已有微型三维解析/挤出路径覆盖方向、整体载荷/力矩、展向分箱加和、壁面量、RANS/LES
  模型量、1/2/4 rank 和重启；
- 对统计 registry、accepted-dt 加权、Reynolds/Favre mean/RMS/covariance、重复事件抑制、
  checkpoint 和异 rank 续算建立发布清单；
- 对不支持的统计组合在启动前明确拒绝，不产生占位零值；
- 核查公式与仓库《算法补充》及其列出的 NASA TMR、经典 RANS/LES/LU-SGS 文献一致。

自动卡口：相关单元/MPI 测试全过；所有输出有限；展向分箱回收到整体量；统计连续/重启一致；
所有五种 LES 和三种 RANS 支持级别有可执行证据。

### PRE-C：发布级本机构建

- 从干净目录配置 Release serial/MPI；
- 执行完整串行/MPI CTest、算法规格、格式检查和安装；
- 安装树完成帮助、配置 dry-run 和小型有限性复验；
- 保留失败记录，任何失败修复后重跑受影响测试和完整矩阵。

### PRE-D：精简源码目录

生成新的 `WCNS_v2.0_pre` 目录，只包含：

```text
include/                    公共头文件
src/                        求解器和运行程序
tools/*.cpp                 CMake 实际构建的必要转换/检查工具
third_party/cgns/           离线构建所需的固定 CGNS 源码归档
docs/                       用户、开发、配置、算法、限制、验证和版本说明
CMakeLists.txt              编译配置
README.md                   版本入口
LICENSE.md                  当前内部许可状态
THIRD_PARTY_NOTICES.md      第三方声明
算法补充.md                 数学与算法规格
WCNS_SOURCE_REVISION        来源提交
PACKAGE_CONTENTS.sha256     全部文件散列
```

目录明确不得包含 `cases/`、`examples/`、`tests/`、`.git/`、build/output/tmp、CGNS 网格、运行场、
checkpoint 或用户数据。打包器必须拒绝未提交的选择文件、路径穿越、重复项和内容散列不一致。

## 5. 统计量支持定义

发布前必须区分三层统计：

1. **瞬时体场/模型量**：由 field registry 逐单元输出，未知量直接失败；
2. **空间积分/截面统计**：全局守恒量、x-z/y-z 平面和槽道壁面量由 MPI 全局求和，禁止重复
   ghost/接口；
3. **接受步时间统计**：只对已注册且可计算的统计量按实际 `accepted_dt` 加权，提供
   Reynolds/Favre mean、RMS 和全部唯一量对 covariance；伪迭代、拒绝步和重复事件不采样。

统计量支持必须同时满足：配置可发现、值有限、量纲缩放一致、MPI 归约一致、checkpoint 身份
完整、同/异 rank 重启连续和用户文档可复现。频谱、自相关置信区间和自动平稳性判断不是当前
内建统计量；文档不得暗示已经提供。

## 6. Git 与验收

- 分支：`release/v2.0-pre`；候选标签：`v2.0-pre-rc.1`；不合入 `main`；
- 设计/版本、代码/打包、测试/验收和发布目录说明分开提交；
- 用户未跟踪 Case05/Case06、`output/`、`tmp/` 始终不修改、不暂存；
- 自动卡口全部通过并完成源码目录后停在最终人工核验；未经人工批准不推送、不合并主干，
  也不创建正式 `v2.0` 标签。

## 7. 完成定义

`v2.0_pre` 完成必须同时满足：

1. 第 1 节全部通用功能具有生产代码、公式/配置文档和本机可执行证据；
2. 串行/MPI Release 完整测试、安装和安装态复验全部通过；
3. 统计量三层支持与重启/MPI 门禁通过，限制说明准确；
4. 没有执行大型算例或目标三维翼型，也没有据此作物理精度声明；
5. `WCNS_v2.0_pre` 目录可从空构建目录离线配置/编译，内容散列通过；
6. 发布目录不含任何算例、测试、运行产物、构建缓存、Git 元数据或用户文件；
7. 形成版本说明和自动验收报告，并停在最终人工核验。
