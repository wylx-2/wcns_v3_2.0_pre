# 周期山 ILES：论文设置核对与 v2.4 实施报告

日期：2026-10-02。基于 v2.3（父提交 `977be30a12b7d066523d7804e2398d2c717ec181`）做独立初场和运行时模块扩展。交付源码快照标记为 `worktree`，实际文件以包内 SHA-256 清单为准。

## 1. 依据与复现范围

用户提供：吴卓航，《高精度有限体积方法的激波捕捉与湍流模拟研究》，清华大学博士学位论文，2026 年 3 月，`test_pdf_3.pdf`。重点是第 5.3.4 节，印刷页 110–112（PDF 第 123–125 页），图 5.16–5.18；低马赫通量见第 5.3.2 节，近壁人工黏性见第 5.3.3 节。

| 项目 | 论文明确给出 | v2.4 算例 |
|---|---|---|
| 雷诺数 | 山高及山顶截面平均速度定义，Re_h=1400 | h=1，Ub=1，rho=1，mu=1/1400 |
| 马赫数 | Ma_b=0.1 | gamma=1.4，R=1，T_ref=71.42857142857143 |
| 计算域 | 9h × 3.035h × 4.5h | x∈[0,9]，顶壁 y=3.035，z∈[0,4.5] |
| 边界 | 上下固壁、流向和展向周期 | 静止无滑移壁；CGNS 双向 1-to-1 平移周期 |
| 驱动 | 由 x=0 截面流量动态调整、空间均匀 | 质量流量反馈 PI，源项为 (0,G,0,0,uG) |
| 粗六面体网格 | 共 101376 单元 | 88×48×24，共 101376 单元 |
| 对比量 | 下壁 tau_w、平均 u、u 脉动二阶矩 | 上下壁 tau/Cf/p；均值和六个 Reynolds 应力分量 |
| 剖面位置 | x/h=0.05、2、4、8 | 相同位置输出独立 CSV |

论文这一节没有交代各方向网格数、精确节点分布、温度壁条件、控制律、初始扰动、时间步及统计窗口。以上 **88×48×24 是对总数的重建选择，不是论文原网格的已知分解**；没有原始网格，不能声称逐节点相同。

论文空间离散是优化四阶变分重构，并讨论近壁人工黏性。本次按用户要求使用现有 WCNS、`turbulence.model=none` 的 ILES，保留分子黏性，依靠现有离散耗散；没有移植论文的变分重构或近壁人工黏性公式。因此属于相同物理参数及同等总单元数下的 WCNS 粗网格试验，不能称为原文算法的精确复现，也不能称为 DNS。上一轮 Re=10595 的调研数据不作为本工况验证数据。

山形采用 [TMR 保存的 Almeida 几何分段多项式](https://tmbwg.github.io/turbmodels/Other_LES_Data/2Dhill_periodic/hill-geometry.dat)，将原 h=28 缩放为 h=1，并在 x=9 周期反射；系数集中在 `include/wcns/physics/periodic_hill.hpp`。

## 2. 补充配置与网格

单个三维挤出结构 zone，底壁 `bottom`、顶壁 `top`，四个周期连接 `imin/imax/kmin/kmax`。允许程序自动分区，统计索引使用原 zone 的 i,j，支持 MPI 重分区续算。

网格映射（xi=i/88，eta=j/48，zeta=k/24）：

\[
x=9[\xi-0.45\sin(2\pi\xi)/(2\pi)],\quad
f=\tfrac12[1+\tanh(2.2(2\eta-1))/\tanh(2.2)],
\]
\[
y=y_b(x)+(3.035-y_b(x))f,\qquad z=4.5\zeta.
\]

双壁加密、山顶附近流向加密、展向均匀。几何沿 i,j 曲线坐标连续，单元物理尺寸不等，不能仅由总单元数断言壁面分辨率已满足 LES。实际 y+、分离剪切层分辨率和统计收敛需要后续服务器计算评估。

新增生成器：`wcns_generate_periodic_hill_cgns output.cgns [nx ny nz]`，默认 88 48 24，输出 ADF-CGNS，拒绝覆盖现有文件。网格已经生成，无需用户再次执行。小网格仅用于测试，不作为交付粗网格结果。

补充选择：上下壁等温 T/T_ref=1，Pr=0.72，常黏度；这样可以排出压力梯度做功引入的热量。论文未明确该热条件。数值方案为 `scmm6_wcns + mdcd_hybrid/primitive + roe_all_speed`，MDCD disp=0.0463783、diss=0.01，Li–Gu 参考 Ma=0.1、速度耗散系数 0.02、压力系数 0.05；SSPRK3，CFL=0.25，无预处理、无显式 SGS。没有为本算例重新标定数值耗散。

初场由流函数构造：令 q=(y-y_b)/(3.035-y_b)，Q=2.035Ub，u0=6Qq(1-q)/(3.035-y_b)，v0=u0 y_b'(1-q)，w0=0；叠加幅值 0.05Ub、在壁面为零且周期的确定性三维扰动。该初场仅用于启动，不能替代充分发展的统计稳态。

## 3. 流量控制

截面面积 A0=2.035×4.5。每个真实单元先按展向宽度 dz 累积 rho*u，在 x=0 两侧单元中心之间作周期线性插值，再按 x=0 的实际网格条带面积积分。输出的两个速度为：

\[
U_m=\dot m/(\rho_0 A_0),\quad U_v=Q_v/A_0.
\]

控制 U_m，低马赫下它与论文所用截面平均速度接近；同时输出 U_v，保留可压缩差异。初始粗网格离散 U_m 略偏离 1，应以历史记录监测后续控制误差。

每个成功物理时间步之后更新下一步均匀力，整个 RK 步保持 G 不变：

\[
e_n=U_{target}-U_{m,n},\quad
G_{n+1}=\operatorname{clip}\{G_n+\rho_0[(e_n-e_{n-1})/\tau+\Delta t_n e_n/\tau^2],-G_{max},G_{max}\}.
\]

默认 G0=0.01、tau=1、Gmax=0.5；裁剪限制累积力，避免无限积分增长。力是正向动量源（等效 -dp/dx），能量源同步使用 uG。`force_next` 表示下一步使用的 G，残差日志仍对应刚完成步的力。需要后续检查流量误差和力是否长期触及上限，短步测试不验证控制器的长期调节质量。

## 4. 统计定义与文件

默认统计窗口 **tUb/h∈[100,1000]**，是预设运行计划，不是论文给定时间，更不保证 t=100 已达到统计稳态。每个成功步取终点样本、用实际接受的 dt 加权，并将 dt 与统计窗口的交集作为权重。终点矩形积分有时间离散误差；未进入窗口时均值表只有表头。

在每个原始 (i,j) 位置先累积展向局部原始矩：rho、u、v、w、p、T、u²、v²、w²、uv、uw、vw、rho*u，再作时间积分。均值为普通 Reynolds 平均，不是 Favre 平均：

\[
\overline{u}=\frac{\sum_n\Delta t_n\sum_k\Delta z_k u_{ijk,n}}{W L_z},\quad
\overline{u'u'}=\overline{u^2}-\overline{u}^{\,2}.
\]

必须先平方再平均，否则会丢失展向脉动。本实现按此顺序。剖面先在各单元形成协方差，再沿相同 eta 层线性插值均值及协方差；不会把相邻单元的平均速度差转换为虚假的脉动。

| 文件后缀 | 内容 |
|---|---|
| `_hill_history.csv` | step、time、下一步 G、质量/体积流量、两种 Ub、瞬时 Re、统计权重、样本数 |
| `_hill_mean_xy.csv` | 各 i,j 的位置、rho、u/Ub、v/Ub、w/Ub、p、T 和六个协方差/Ub² |
| `_hill_profiles.csv` | x/h=0.05、2、4、8 的同类剖面；实际 y/h 随山形变化 |
| `_hill_wall.csv` | x/h、下壁高度、上下壁有符号 tau、Cf 与外推压力 |

所有 hill CSV 固定采用内部无量纲定义：长度/h，p 和 tau 的尺度为 rho_ref U_ref²；Cf=tau/(0.5 rho0 Ub²)。论文图 5.17 标为 tau_w，不能未经归一化核对就直接把 Cf 当作同一纵轴。两壁正 tau 均表示沿正 x 方向附着流。壁面导数使用最邻近两个单元和零壁速构造二次单边导数，再按壁面法向投影；这是独立后处理估计，不等同于求解器面黏性通量的逐项输出。分离/再附可由平均下壁 tau 零点评估。

周期山状态保存在检查点描述符 `WCNS_PeriodicHill`：G、前一步误差、最后步号/时间、样本数、累计时间、全部时间积分及壁面积分。严格续算校验工况和统计窗口签名；更改 `hill.write_every_steps` 不改变物理定义，允许修改。`restart.mode=algorithm_change` 按原程序契约重新开始控制器与统计，不能当作无缝累计。关闭 hill 时，原有 restart signature 保持不变。

模块目前限定一个标准尺寸的三维挤出源 zone、x/z 周期、静止无滑移双壁、常黏度、无湍流模型、SSPRK3、无预处理及重试。多 source-zone、旋转周期、移动壁、RANS/显式 LES、双时间推进不在本次支持范围。

## 5. 配置键与运行

| 键 | 默认值／含义 |
|---|---|
| `hill.enabled` | false，开启新模块 |
| `hill.bulk_velocity`, `hill.density` | 1，控制目标和参考截面密度 |
| `hill.controller_time` | 1，控制时间尺度 |
| `hill.force_limit` | 0.5，均匀力绝对上限 |
| `hill.statistics.start/end` | 100 / 1000，时间平均窗口 |
| `hill.write_every_steps` | 100，CSV 更新间隔；末步也输出 |
| `initial.type` | 新增 `periodic_hill` |
| `initial.bulk_velocity` | 1 |
| `initial.perturbation_amplitude` | 0.05，可取 [0,0.2] |

配套案例包含 `smoke.wcns`（3 步硬上限）、`production.wcns`（服务器长算计划）、`production_restart.wcns`（同定义严格续算）、`grids/hill_88x48x24.cgns`。运行命令和退出码见案例 README。smoke 从 t=0 统计以验收输出链，production 从 t=100 统计；因此 **不能把 smoke 的检查点直接按 strict 模式接到 production**。

长算应在目标服务器先执行同包 smoke，再启动 production。首次长段之后检查质量守恒、Um/Uv、力限幅、均值漂移、块平均差异和 y+，必要时延长启动及采样。论文曲线的定量误差、再附位置和网格无关性尚未验证。
